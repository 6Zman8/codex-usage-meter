# 카드 안쪽 항목 배치

## 범위

사용자 요청: 카드 전체뿐 아니라 **각 항목의 크기와 위치**를 직접 조절합니다. 기존 `⚙ 설정 → 배치 편집`에 항목 편집을 추가하고 전체/위젯·계정별로 따로 저장합니다.

대상은 계정 제목/연결 버튼, 단기·주간 한도, 갱신 시간, 초기화권/구독, 사용 통계, 달력과 PC 지표입니다. 항목 안의 글자·게이지는 비율을 유지하여 함께 확대/축소합니다. 항목을 끌어 이동하고 모서리로 크기를 바꿉니다. 선택 목록으로 겹친 항목도 선택하며 항목/카드 안쪽 배치 초기화와 취소를 제공합니다.

## 설계와 보존

- 기존 자동 배치는 수정하기 전까지 유지합니다. 처음 수정할 때 현재 항목 위치를 카드 내부에 대한 비율로 저장합니다.
- 저장은 기존 LayoutV1 설정의 확장 필드를 이용하며 이전 설정, 표시/숨김, 카드 순서·크기와 전체/위젯 분리를 유지합니다.
- 실제 표시 요소를 그대로 사용해 데이터 갱신과 버튼 동작을 유지합니다. 편집 미리보기에서는 계정 전환·종료 같은 실제 동작을 계속 차단합니다.
- 카드 경계 안에서 위치와 크기를 제한하며 기본 비율을 유지합니다. 편집 설정 목록은 축소하지 않고 스크롤하여 읽을 수 있게 합니다.
- 이력 그래프(v1.4.2), 계정 자료·로그인·세션, 실행 중인 미터기와 Codex는 보존합니다.

## 체크포인트

- 조사/범위 확정: 개별 항목 이동·크기 조절, 계정/PC와 전체/위젯 지원.
- 구현 완료: 기존 LayoutV1에 항목별 비율 위치·크기를 저장하고, 실제 내용물의 비율 변환으로 데이터 갱신과 조작 영역을 유지합니다. 계정과 PC, 전체와 위젯을 따로 편집합니다.
- 검증 완료: 숨김 WPF에서 실제 이동/크기 손잡이, 경계·최소 크기, 저장·취소·기본 복원, 새 프로세스 복원, 100~200% 글씨·좁은 창, 이동한 버튼의 조작 영역과 계정 페이지 분리를 확인했습니다. 전체 검사 70개, 계정 전환 검사 13개, userscript 4개가 통과했습니다.
- 리뷰 반영: 장치 재생성 후 현재 항목을 다시 찾아 이동, 표시 목록 변경 즉시 반영, 편집 종료 후 버튼의 원래 클릭 속성 복원, 열린 이력의 임시 숨김·복원을 수정하고 재현 검사를 통과했습니다.
- 배포 완료: v1.5.0 정식 Release·공개 실행파일 재검사와 v1.4.0/v1.4.2 내장 업데이트 검색·다운로드 검증을 마쳤습니다. 최종 실행파일은 프로젝트 `bin/CodexUsageMeter.exe`에 보관하고 이전 버전 복구본과 검사 자료를 유지합니다. [검증 기록](releases/v1.5.0-verification.md)을 참고하세요.
- 완료 조건: 기존 배치 보존, 개별 항목 편집·저장·재실행 복원, 경계/조작 영역/작은 화면/글씨 배율 검증, 기존 회귀검사, 공개 실행파일·내장 업데이트 검증과 산출물 보관.

## v1.5.1 후속 개선

- 사용자 피드백: 편집창을 최대화할 수 없고 미리보기가 작아 조작하기 어려우며 기본 내용물도 몰려 보임.
- 원인: 제목 표시줄에 닫기만 있고 더블클릭은 이동만 처리함. 미리보기는 축소 전용 Viewbox였으며 위젯 게이지 묶음은 카드 폭과 무관하게 368로 고정됨.
- 구현: 최대화/복원·제목 더블클릭, 25~400% 확대·축소·실제 크기·화면에 맞춤·Ctrl+휠과 스크롤. 위젯의 유동 폭과 넓어진 기본 간격, 전체 카드 행/PC 지표 여백을 함께 반영.
- 검증 완료: 배치 32개, 전체 72개, 계정 전환 13개와 userscript 4개 통과. 리뷰에서 찾은 좁은 카드의 오른쪽 넘침, 이전 저장 크기 축소와 연속 휠 확대 기준점 이동을 재현·수정했습니다.
- 배포 완료: 정식 v1.5.1 공개 실행파일 재검사와 v1.5.0의 내장 업데이트 검색·다운로드·해시 검증을 마쳤습니다. 검사 자료는 `artifacts/editor-zoom-v1.5.1`, 최종 실행파일은 `bin/CodexUsageMeter.exe`에 보관합니다. [검증 기록](releases/v1.5.1-verification.md)을 참고하세요.

## v1.8.0 자석 정렬과 기존 배치 보존

항목 이동·크기조절 시 보이는 다른 항목과 카드 안쪽의 경계·중앙선에 맞춰지고 파란 안내선이 표시됩니다. 화면 기준 6 DIP 이내에서 적용하며 `Alt`로 일시 해제합니다. 크기조절의 비율·최소 크기·카드 경계를 유지합니다.

정렬은 직접 드래그할 때만 적용합니다. 기존 `LayoutV1` 키·항목 ID를 유지하고 저장된 좌표를 반올림하지 않습니다. 업데이트·불러오기·미리보기 확대·글씨 확대·Windows 위젯 렌더링으로 저장 배치를 재정렬하지 않습니다. 새 기본 배치는 `CompactPcSpacing`으로 PC 카드 높이를 줄이며, 이 필드가 없는 기존 배치는 이전 카드 높이를 유지해 다른 카드의 좌표 공간도 보존합니다. 기존 PC 카드도 게이지 자체는 세로 막대로 바뀌며, 높이는 배치 편집에서 직접 조절할 수 있습니다.

## v1.8.1 PC 내부 배치 수정

v1.8.0의 원형용 2×2 배치·높이 보존 처리는 제거했습니다. PC 막대는 한 줄로 배치되고 조절박스는 실제 이름·막대·수치에 맞습니다. 다른 카드와 같은 높이로 강제 확장하지 않습니다.

업데이트 시 이전 PC 내부 좌표만 `PreviousPcItemLayouts`로 보존하고 새 기본 배치를 적용합니다. 다른 카드의 저장 설정과 PC 카드의 순서·표시/숨김은 유지합니다. `PcBarLayout`이 전환 완료를 기록하므로 이후 직접 저장한 PC 배치는 재실행·업데이트로 초기화하지 않습니다.
