# v1.9.0

## 추가된 기능

- 계정 카드의 **연결**에서 GPT/Codex 또는 Claude를 선택할 수 있습니다. 총 1~4개 계정을 섞어 표시하고, 전체 화면과 위젯에서 서비스별 표식·이름으로 구분합니다.
- Claude 구독의 5시간·주간 잔여량과 초기화 시간을 백그라운드에서 조회하는 연결부를 추가했습니다. 기존 Codex 계정·이력·배치와 각 서비스의 인증 폴더는 분리해 보존합니다.
- PC 카드의 **이력**에서 CPU·RAM·GPU·디스크·네트워크의 최근 30분 그래프를 볼 수 있습니다. **← 현재**로 돌아옵니다. 기록은 실행 중 메모리에만 보관하며 재실행하면 초기화됩니다.
- 센서 오류와 미측정 구간은 실제 0과 구분합니다. Windows 위젯은 서비스 표시를 반영하면서 이미지의 픽셀과 해상도를 유지하고 전송 크기를 줄입니다.

## Claude 연결 안내

Claude Code CLI가 필요합니다. 미터기 카드에서 Claude를 선택한 뒤 구독 계정으로 로그인하세요. 미터기를 위해 대화를 시작하거나 API 키를 입력할 필요는 없습니다. 기존 Claude Code·Mixdog 로그인 정보를 자동으로 가져오지 않습니다.

**Claude 실계정 로그인·사용량 조회·인증 자동 갱신은 아직 실사용 확인 전입니다.** 구독 한도 조회는 공식 외부 연동이 보장된 공개 API가 아니므로 Anthropic의 정책이나 서버 변경으로 제한될 수 있습니다.

Gemini 등은 추후 연결부를 추가할 수 있도록 구조만 준비했으며, 이번 버전에서는 선택할 수 없습니다.

## 업데이트

미터기의 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요. Windows 위젯을 사용 중이면 업데이트 후 **Windows 위젯 추가 / 업데이트**도 눌러 주세요.
