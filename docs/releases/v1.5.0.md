# v1.5.0 — 카드 안쪽 항목 이동·크기 조절

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받은 뒤 **⚙ 설정 → 배치 편집 → 카드 선택 → 항목 편집**을 누르세요. 항목을 끌어 위치를 옮기고, 선택한 항목 오른쪽 아래 **◢**를 끌어 크기를 조절합니다. 마지막에 **배치 저장**을 누르세요.

- 계정 카드의 제목·버튼, 단기·주간 게이지, 갱신 시간, 초기화권·구독, 통계·달력과 PC 지표를 개별 조절합니다. 각 항목 안의 글자와 게이지는 비율을 유지합니다.
- 전체 화면과 위젯, 각 계정·PC의 배치를 따로 저장하며 재실행 후 복원합니다. 기존 설정은 유지하고, 직접 편집하기 전에는 자동 배치를 사용합니다.
- 겹친 항목은 왼쪽 목록에서 선택합니다. **선택 항목 원래대로 / 카드 안쪽 모두 원래대로**, 저장과 취소를 지원합니다. 설정 목록을 스크롤할 수 있어 작은 편집창에서도 조절 항목에 접근할 수 있습니다.
- 항목은 카드 경계 안에서 이동·확대됩니다. 표시/숨김 또는 PC 장치 목록 변경 후에도 선택 목록과 이동 손잡이가 현재 항목을 따라갑니다.
- 이력은 계속 기존 카드 안에서 그래프·표·초기화 전 잔여량으로 확인합니다. 배치 편집 중에는 현재 내용물을 표시하고, 같은 계정의 열린 이력은 편집 종료 후 다시 표시합니다.

전체 검사 70개, 계정 전환 관련 격리 검사 13개와 정식 Release의 내장 업데이트 검색·다운로드 검증을 통과했습니다. 실제 계정 전환이나 사용 중인 프로그램 교체는 하지 않았습니다. 자세한 결과는 [검증 기록](v1.5.0-verification.md)을 참고하세요.
