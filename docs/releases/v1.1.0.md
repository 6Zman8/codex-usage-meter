# v1.1.0 — 전체·위젯 배치 편집

`⚙ 설정 → 배치 편집`에서 현재 화면을 원하는 구성으로 바꾸세요. 제목 표시줄의 오른쪽 클릭으로도 열 수 있습니다.

- 전체 화면과 위젯에 별도의 배치 저장.
- 계정/PC 카드 숨김·표시, 목록의 ☰ 드래그 또는 위·아래 이동, 1~3칸 폭, 3단계 높이, 최대 1~3열 배치.
- 계정 카드의 단기·주간·초기화권, 전체 화면의 통계·달력, PC 카드의 CPU·GPU·RAM·디스크·네트워크 선택.
- 선택 계정만 표시하는 ‘한 계정 중심’ 배치와 현재 화면 기본값 복원. 숨긴 계정의 연결·자료·계정 칸 수는 유지.
- 편집 중 실시간 미리보기, 저장, 취소/닫기로 되돌리기. 저장 실패 시 편집창과 오류 안내 유지.
- 정상 응답에 없는 한도를 자동 숨김. 조회 실패나 미연결 상태는 자동 숨김 대상에서 제외.
- 빈 계정 자리 회수, 좁은 창의 줄바꿈·스크롤, 작은 제목 표시줄과 큰 글씨의 게이지 배치 개선.

## 검증

새 `--layout-self-test`는 사용자 계정을 열거나 실제 창을 표시하지 않습니다. 저장·새 프로세스 복원, 모드 독립성, 잘못된 설정 복구, 편집 취소, 저장 실패, 실제 계정 페이지 바인딩, 폭/순서 반영, 100~200% 글씨와 좁은 창을 검사합니다. 검사 이미지는 가상 계정 데이터를 사용합니다.

기존 사용량·업데이트 안내·계정 전환·전체 검사와 프로세스 독립 실행 검사도 유지합니다. 실제 사용자 계정 전환이나 Codex 재시작은 이번 기능 검증에서 수행하지 않습니다. 다른 PC의 실제 동작은 해당 PC에서 별도로 확인해야 합니다.

## 저장과 호환성

배치는 기존 계정 자료와 별도로 `HKCU\Software\CodexUsageMeter\LayoutV1`에 저장합니다. 이전 버전 설정은 유지하며, 새 배치 값이 없거나 손상되었으면 기본 배치로 시작합니다. 배치를 저장하기 전에는 손상된 값을 덮어쓰지 않습니다. 계정 인증·대화·세션을 Git이나 다른 PC로 복사하지 않습니다.
