# v1.9.3

- PC 이력 버튼을 계정 1 이력 버튼과 같은 높이·여백·글씨 크기로 맞췄습니다.
- PC 이력 지표 목록을 펼쳐 읽는 동안 주기적 갱신이 목록·선택·스크롤을 바꾸지 않습니다. 그래프는 계속 갱신됩니다.
- 목록을 닫으면 최신 장치 이름·추가·제거를 반영하고 같은 지표의 선택을 유지합니다. 사라진 지표는 첫 지표로 전환합니다.
- 변경 없는 지표 목록은 닫힌 상태에서도 교체하지 않습니다.
- 배치 편집으로 옮길 때 실제 대시보드의 글씨 크기·측정 방식을 유지하여 계정 제목줄의 위치·간격과 카드 크기가 달라지는 문제를 수정했습니다. 저장된 배치는 변경하지 않습니다.

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 적용합니다.
