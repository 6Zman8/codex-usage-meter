# v1.2.1 — 계정 칸 정렬과 스크롤 없는 대시보드

- 5시간 한도를 제공하지 않는 계정도 같은 위치에 해당 칸을 유지합니다. 주간·초기화권·통계·달력의 줄이 다른 계정과 어긋나지 않습니다.
- 전체·위젯 화면의 스크롤을 제거했습니다. 카드와 그 안의 내용이 창 안에 모두 들어오도록 크기를 맞춥니다. 좁은 창에서는 내용 크기도 줄어듭니다.
- 배치 편집의 실제 미리보기와 조절 항목도 스크롤 없이 표시합니다. 전체와 위젯 각각의 카드 표시·순서·폭·높이를 저장할 수 있습니다.
- 별도의 범용 구독 카드와 일정 등록 화면을 제거했습니다. 이전에 입력한 자료는 설정에 보존합니다.
- 각 Codex 계정의 초기화권 아래에 구독 정보를 자동 조회하여 갱신일·종료일·확인된 이용 기간을 구분해 표시합니다. 현재 환경에서는 결제 API가 HTTP 403 보안 확인으로 차단됩니다. 이 경우 `구독 날짜 조회 불가`와 이유를 표시하며 오래된 로그인 자료나 토큰 만료일로 대체하지 않습니다.

## 전달

기존 프로그램의 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 적용합니다.

## 검증

배포 전 전체·계정 전환·배치 숨김 검사가 종료 코드 0입니다. 창 크기와 100~200% 글자 배율에서 카드 전체 표시, 누락 한도/오류 안내의 줄 정렬, 100% 값과 남은 시간의 겹침·잘림, 실제 배치 편집의 저장·취소를 확인했습니다. 구독 조회는 다른 계정·플랜의 날짜 차단, 캐시, 실패 사유와 오래된 날짜 제외를 검사했습니다.

현재 연결된 두 계정에서 새 구독 조회 코드는 HTTP 403 보안 확인을 반환했고 날짜를 표시하지 않았습니다. 인증파일 해시는 전후 동일했습니다. 실제 구독 날짜를 가져오는 부분은 아직 완료되지 않았습니다.

작업 자료는 `artifacts/account-ui-20261006`에 보관합니다.
