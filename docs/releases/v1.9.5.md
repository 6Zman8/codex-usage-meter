# v1.9.5

- PC 상태의 디스크 제목을 `디스크 0` 같은 번호 대신 `C:`, `D:` 드라이브 문자로 표시합니다.
- 한 물리 디스크에 여러 드라이브 문자가 있으면 `C: D:`처럼 함께 표시하며, 문자가 없는 장치는 기존 디스크 번호를 유지합니다.
- 전체 화면·작은 위젯·Windows 위젯·배치 미리보기·PC 이력에 같은 이름을 사용합니다.
- 물리 디스크 단위의 사용률·읽기·쓰기 측정, 위젯에 표시할 디스크 선택, 저장된 배치와 이력 식별자는 변경하지 않습니다.

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 적용합니다.
