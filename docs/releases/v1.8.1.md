# v1.8.1

- PC 상태를 실제 세로 막대용 한 줄 배치로 바꿉니다. 항목을 편집해도 이전 2×2 배치로 돌아가지 않습니다.
- 조절박스는 이름·막대·수치의 실제 영역에 맞추며, PC 카드가 계정 카드 높이에 맞춰 불필요하게 늘어나지 않습니다.
- 이전 PC 내부 배치만 한 번 새 형태로 전환합니다. 원래 좌표는 `PreviousPcItemLayouts`에 보존합니다. 카드 순서·표시/숨김·다른 카드의 저장 설정은 유지하며, 전환 후 새로 저장한 PC 위치는 재실행과 이후 업데이트에서도 유지합니다.
- Windows 위젯 설치 후 패키지 등록뿐 아니라 위젯 확장·버전·실행 구성요소의 인식 결과를 확인합니다.
- **등록됨 / 확장 미인식 / 확인 불가**를 구분합니다. 확장 인식 성공도 실제 위젯 보드 추가·고정 성공으로 안내하지 않습니다.
- 위젯 목록에 보이지 않으면 설치 결과의 **진단 복사**로 Windows 빌드·아키텍처·Web Experience Pack·제공자 버전·검사 결과를 전달할 수 있습니다. 계정·인증정보는 수집하지 않습니다.

기존 앱의 **설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받습니다. 위젯 보드는 **Windows 키 + W**입니다. 노트북에서 표시되지 않는 실제 원인은 해당 PC의 진단 결과와 구분해 확인해야 합니다.
