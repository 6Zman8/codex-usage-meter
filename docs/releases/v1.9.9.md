# v1.9.9

- Claude 연결이 Claude Code CLI 대신 브라우저 로그인(OAuth PKCE, 로컬 콜백)을 사용합니다. CLI가 설치되지 않은 PC에서도 연결할 수 있습니다.
- 로그인 후 프로필에서 구독 플랜(Pro·Max·Team·Enterprise)을 확인해 저장하며, 이전 CLI로 만든 연결은 그대로 사용합니다.
- 연결 해제는 해당 칸의 미터기 인증 파일만 삭제합니다. Claude Code·Mixdog 로그인은 변경하지 않습니다.
- 검사: 공급자 회귀검사에 로그인 요청 형식, 위조 콜백 거부, 코드 교환, 플랜 판별, 취소·로그아웃을 추가했습니다. 실제 Claude Pro 계정으로 로그인과 5시간·주간 사용량 조회를 확인했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
