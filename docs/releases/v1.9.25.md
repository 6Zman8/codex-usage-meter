# v1.9.25

- **업데이트 자동 확인**: 미터기를 시작할 때와 이후 6시간마다 GitHub에서 새 버전을 자동으로 확인합니다.
- **제목줄 업데이트 버튼**: 새 버전이 있을 때만 전체 화면의 `위젯` 버튼 옆에 `⬆ 업데이트`, 위젯 화면의 `전체` 버튼 옆에 `⬆` 버튼이 나타납니다. 누르면 최신 버전을 다시 확인한 뒤 다운로드 및 재시작 안내가 뜹니다. 새 버전이 없으면 버튼은 보이지 않습니다.
- 설정의 `업데이트 확인` 버튼도 그대로 쓸 수 있으며, 자동 확인 결과를 상태 문구로 보여 줍니다.

검사: 전체 자체 검사(`--self-test`)와 업데이트 화면 검사(`--update-ui-self-test`)를 통과했으며, 제목줄 업데이트 버튼의 표시·숨김과 좁은 창에서 누를 수 있는지 검사를 추가했습니다.

이번 버전까지는 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요. 다음 버전부터는 제목줄의 업데이트 버튼으로 받을 수 있습니다.
