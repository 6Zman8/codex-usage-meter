# Codex Usage Meter 1.0.8

Pro Lite 업그레이드 후 주간 사용량이 5시간 칸에 들어가거나 이전 Plus 요금제로 표시되는 문제를 수정했습니다.

- 서버가 주간 한도를 첫 번째 항목으로 보내도 실제 기간을 보고 주간 칸에 표시합니다.
- 서버가 제공하지 않는 단기 한도는 전체 화면에 `미제공`, 위젯에 `없음`으로 표시합니다. 누락된 사용량을 잔여 100%로 만들지 않습니다.
- 사용량 응답의 최신 요금제를 로그인 당시의 요금제보다 우선하며 `prolite`는 `Pro Lite`로 표시합니다.
- 여러 한도 묶음이 있을 때 Codex 전용 항목을 우선합니다. 관계없는 항목을 임의로 선택하지 않습니다.
- Plus처럼 5시간과 주간 한도가 모두 있는 계정은 두 한도를 계속 표시합니다. 위젯의 기간 이름도 응답에 맞춰 표시합니다.
- 사용량 해석 및 실제 WPF 위젯/전체 화면 회귀검사를 배포 자동화에 추가했습니다.

## 업데이트

각 기기에서 미터기의 `⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작`을 누르세요. 버전이 `1.0.8`인지 확인하고 새로고침을 누르면 됩니다. 계정을 해제하거나 다시 등록할 필요 없이 기존 연결로 조회합니다.

이 수정은 요금제와 한도 표시를 고칩니다. 특정 기기에서 계속 정보가 안 나오면 해당 기기의 오류 문구와 Codex 설치 상태를 별도로 확인해야 합니다. 원격 기기의 실제 실행을 로컬 검사만으로 보장하지 않습니다.
