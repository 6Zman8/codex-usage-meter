# v1.9.29

- **폰 리모컨**: 원격 접속 없이 폰에서 PC 화면 끄기·절전을 실행합니다. **⚙ 설정 → 폰 리모컨**을 켜고 나온 QR 코드를 폰 카메라로 찍으면 리모컨 페이지가 열립니다. 브라우저 메뉴의 **홈 화면에 추가**로 아이콘을 만들어 두면 다음부터는 아이콘만 누르면 됩니다. 앱 설치는 필요 없고, 폰이 PC와 같은 공유기(와이파이)에 연결돼 있어야 합니다.
- 폰 화면의 버튼도 PC와 같이 1.2초 꾹 누르면 게이지가 차고, 끝까지 차야 실행됩니다. 중간에 손을 떼거나 손가락이 버튼 밖으로 나가면 취소됩니다.
- 리모컨 주소에는 추측할 수 없는 비밀 값(128비트)이 들어갑니다. 링크를 모르는 사람은 같은 와이파이에 있어도 페이지를 열거나 요청을 보낼 수 없습니다. **새 링크 만들기**를 누르면 이전 링크는 바로 쓸 수 없게 됩니다.
- 기본으로 꺼져 있습니다. 처음 켤 때 Windows 방화벽 창이 뜨면 **액세스 허용**을 눌러야 폰에서 연결됩니다(포트 43130).
- 절전된 PC를 폰에서 다시 켜는 기능은 없습니다. PC의 키보드·마우스를 눌러 깨우세요.

검사: 새 `--phone-remote-self-test`(전체 검사와 배포 워크플로에 포함)가 다음을 확인합니다.
- QR 코드: 버전 1·4·6과 고정 마스크에서 참조 구현(Nayuki qrcodegen)과 모든 칸이 일치하는지, 화면 이미지가 행렬과 같은지.
- 리모컨 서버: 실제 소켓 요청으로 비밀 경로 외 접근 404, 리모컨 헤더 없는 요청 403, GET 요청의 실행 거부, 본문·과대 헤더 거부, 느린 요청의 제한 시간, 정상 요청 하나당 동작 한 번.
- 켜기·끄기 흐름: 다른 프로그램이 실행 중인 상태에서 켜기 → 새 링크(같은 포트에서 이전 링크 즉시 차단) → 끄기(포트 닫힘) → 다시 켜기 → 종료(포트 닫힘). 미터기가 Codex 등을 실행할 때 연결 포트가 그 프로그램에 복제되지 않게 막았고, 이 막음을 빼면 검사가 실패하는 것도 확인했습니다.
- 설정 화면: QR 코드가 설정 창 스크롤 영역 안에 200px로 다 보이는지. 그려진 화면은 OpenCV로 링크 해독까지 확인했습니다.

실제 폰으로 QR을 찍어 연결하고 화면 끄기·절전을 실행하는 것은 아직 확인하지 않았습니다.
