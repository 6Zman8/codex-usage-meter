# Codex Usage Meter 1.0.7

업데이트 안내가 창 아래로 잘려 다운로드 버튼을 누르지 못하던 문제와 한글 변경사항이 깨지던 문제를 수정했습니다.

- 긴 안내 내용은 창 안에서 스크롤되고, 다운로드·나중에 버튼은 아래에 표시됩니다.
- 작은 창과 글자 크기 200%에서도 버튼 글자가 줄바꿈됩니다.
- 새 안내를 열면 스크롤이 맨 위로 돌아가며, 연결 코드도 끝까지 볼 수 있습니다.
- GitHub의 한글 안내를 UTF-8로 읽습니다.
- 공개 업데이트 요약은 이전 버전도 표시할 수 있도록 짧은 영문으로 유지합니다.
- 작은 창, 큰 글씨, 버튼 클릭 영역, 연결 코드, 한글 응답 검사를 배포 전에 자동으로 실행합니다.

기존 안내창이 잘려 있다면 `Esc`를 두 번 눌러 닫고 `⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작`을 누르세요. 1.0.6의 Codex 재연결·계정 전환 수정도 포함합니다.
