# v1.9.30

- **폰 리모컨이 "연결할 수 없음"으로 뜨던 문제**: 미터기는 폰 연결을 기다리고 있었지만 Windows 방화벽에 허용 규칙이 없어 막혔습니다. 새 프로그램이 연결을 기다릴 때 알려 주는 Windows 설정이 꺼진 PC에서는 허용 창도 뜨지 않았습니다.
- 이제 미터기가 방화벽 상태를 직접 확인합니다. 막혀 있으면 **⚙ 설정 → 폰 리모컨**에 이유와 **방화벽 허용** 버튼을 보여 줍니다. 버튼을 누르고 관리자 승인 창에서 **예**를 누르면, 미터기 프로그램의 TCP 43130 포트만 '개인 네트워크'에서 허용하는 규칙이 추가됩니다.
- PC 네트워크가 '공용'으로 잡혀 있으면 그 이유도 안내합니다.
- 스토어 앱·서비스 전용 규칙은 미터기를 허용하는 규칙으로 잘못 세지 않습니다.
- 처음 켤 때 방화벽 창이 뜬다는 잘못된 안내 문구를 고쳤습니다.
- 사용자 결정에 따라 외부(데이터 통신) 접속과 절전된 PC 켜기(Wake-on-LAN)는 넣지 않았습니다.

검사: `--phone-remote-self-test`에 방화벽 막힘·공용 네트워크 안내와 허용 후 갱신, 규칙 범위(이 프로그램·이 포트·개인 네트워크), 패키지 전용 규칙 제외, 관리자 권한 없이 정책 읽기를 추가했습니다. 실제 관리자 승인과 폰 연결은 이 PC에서 직접 확인이 필요합니다.
