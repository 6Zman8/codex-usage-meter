## 보존과 미확인

기존 앱·제공자 프로세스와 실행파일, 실제 LayoutV1이 검사 전후 유지됨을 확인했습니다. 사용자 계정·인증·세션을 전환하거나 복사하지 않았으며 `.mixdog/`와 기존 미추적 계획 파일은 커밋하지 않았습니다.

실제 앱 교체·제공자 등록·Win+W 보드 고정은 실행하지 않았습니다. 노트북 미표시의 실제 원인은 아직 확인하지 못했습니다. 노트북 업데이트 후 **Windows 위젯 추가 / 업데이트 → 진단 복사** 결과로 Windows 빌드·아키텍처·Web Experience Pack·제공자 버전과 인식 실패를 확인해야 합니다.
