# v1.6.0

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 업데이트하세요.

- 트레이에 숨긴 미터기를 작업표시줄 고정 아이콘으로 다시 실행하면 기존 창이 열립니다. 실행 중이라는 안내만 나오는 동작을 수정했습니다. 최소화·반복 실행·시작 중 재실행도 처리합니다.
- **Windows 위젯 추가 / 업데이트**로 Windows 11 위젯 보드용 구성요소를 받을 수 있습니다. 등록 후 **Win+W → 위젯 추가 → Codex 사용량**을 고정하세요. GitHub 배포판의 최초 로컬 등록에는 Windows 개발자 모드가 필요합니다.
- **자동 시작 시 트레이로**를 켜면 Windows 로그인 때 창을 띄우지 않고 시작합니다. 위젯의 새로고침도 창을 띄우지 않습니다.
- 위젯에는 계정별 잔여 비율·초기화·실제 관측 시각과 자료 상태를 전달합니다. 이메일·인증정보를 전달하지 않으며 미제공·조회 실패를 잔여량 0%로 표시하지 않습니다.

기존 계정·로그인·사용량 이력·창 배치는 유지합니다. 실행 중인 사용자의 Codex 종료나 실제 계정 전환을 검사에 사용하지 않습니다. 상세 사용법과 설치 조건은 [Windows 위젯 안내](../WINDOWS_WIDGETS.md)를 참고하세요.
