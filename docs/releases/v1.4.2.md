# v1.4.2 — 카드 안에서 보는 사용량 이력 그래프

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작** 후 계정 카드의 **이력**을 누르세요. 새 창 없이 해당 카드 내용이 단기·주간 잔여량 그래프로 바뀌고 **← 현재**로 돌아옵니다. 전체 화면과 위젯 모두 지원하며 다른 카드의 위치와 크기를 유지합니다.

- 민트색 단기·보라색 주간 잔여량을 실제 시간축과 0~100% 축에 표시합니다. 선과 점에 마우스를 올리면 확인 시각·잔여 비율·예정 초기화·플랜이 표시됩니다.
- 보기 목록에서 **기록 표 / 초기화 전**으로 전환하고, 저장 계정과 최근 7/30/90일·전체 기간을 고를 수 있습니다.
- 2분을 넘는 관측 공백, 초기화·플랜·한도 변경과 값 증가는 선을 끊습니다. 단일 기록은 점으로 표시하며 결측을 0%로 만들지 않습니다.
- 기존 기록, 초기화 전 마지막 확인값과 저장 파일 형식은 유지합니다. 정상 갱신 시 보기를 유지하고, 연결 계정이나 계정 페이지 변경 시 이전 계정 이력은 닫습니다.

## 검증과 배포 체크포인트

- 그래프·카드 전환·관측 공백·계정 분리 등을 포함한 이력 검사 20개, 전체 검사 68개, 계정 전환 검사 13개가 로컬에서 통과했습니다.
- 두 실제 저장 계정의 기록을 읽기 전용으로 불러와 그래프의 자료 일치와 숨김 렌더를 확인했습니다. 인증·기록 원본을 변경하지 않았습니다.
- v1.4.1의 GitHub 검사는 브라우저 연동 거부 응답의 본문을 읽다 연결이 끊겨 게시 전에 중단됐습니다. 기존 태그는 유지하고 v1.4.2로 재검증합니다. 잘못된 인증·호스트·OPTIONS 시험은 본문을 보내기 전에 완전한 거부 응답을 확인하도록 바꿨으며, 상태 코드·본문 수신·저장 부작용 검사는 유지합니다. 브라우저 연동 제품 코드는 변경하지 않았습니다.
- 남은 단계: v1.4.2 최종 빌드·공개 Release·이전 버전 내장 업데이트 검증, 최종 실행파일 보관과 임시자료 정리.
