# Codex Usage Meter 1.0.9

계정 전환 시 Codex에서 실행된 미터기가 상위 작업과 함께 종료될 수 있는 경로를 개선했습니다. 일시적인 프로세스 조회·실행·통신 실패를 제한된 횟수로 자동 복구하고 전환 중 종료를 방지합니다.

## 바뀐 동작

- Codex나 터미널·업데이트 도우미에서 실행해도 미터기는 Windows 탐색기를 부모로 독립 실행합니다. 계정 전환 전에 이 상태를 확인하고, 확인에 실패하면 Codex를 종료하거나 인증을 변경하지 않습니다.
- 종료 요청 직후 강제 종료하던 유예 시간을 0.75초에서 3초로 늘려 정상 종료 시간을 확보합니다. 강제 종료가 필요할 때는 보관한 프로세스 핸들을 사용하여 재사용된 PID의 다른 프로그램을 종료하지 않습니다.
- 일시적인 프로세스 조회 경합(Windows 오류 299/87)은 최대 2회 더 확인합니다. 권한 오류나 계속되는 실패를 빈 프로세스 목록으로 간주하지 않습니다.
- Windows의 패키지 활성화 API로 실행 요청 결과를 확인합니다. 실행 인스턴스가 없을 때에만 최대 3회 활성화를 시도하며, 창과 백엔드가 3초간 안정적이어야 성공으로 판단합니다.
- 요금제/사용량 조회 연결이 끊기거나 응답이 늦으면 한 번 재연결합니다. 로그인/로그아웃/인증 실패는 자동 반복하지 않습니다. 전환할 때마다 불필요하게 토큰 갱신을 강제하지 않습니다.
- Codex 패키지 이름으로 식별하므로 버전 숫자나 데스크톱 EXE 이름이 바뀌어도 대응합니다. 이전 버전은 검증된 설치 경로 규칙으로 호환합니다.
- 계정 전환 중 창의 X·트레이 종료·프로그램 업데이트를 막고, 전환 뒤 버튼과 주기 갱신을 복원합니다. 계정 변경 알림이 몰리면 중복 조회를 합칩니다.
- 재실행 뒤 선택 계정이 유지됐는지도 확인합니다. 그 사이 다른 로그인이 기록됐다면 성공으로 표시하거나 덮어쓰지 않고 현재 로그인을 보존합니다.
- 사전검사/실행 재시도 기록을 추가했습니다. 계정 번호와 단계·오류 종류만 기록하며 토큰/이메일은 추가하지 않습니다.

## 검증과 한계

실제 Windows 시험용 Job을 종료해 일반 자식 프로세스의 동반 종료와 독립 실행 자식의 생존을 비교합니다. 사용자 Codex나 계정을 종료하지 않는 테스트입니다. 가짜 계정 파일을 사용하는 회귀검사로 전환 순서·일시 실패·롤백·UI 종료 방지·조회 재시도를 검증합니다.

실행 중인 Codex 데스크톱을 저장된 다른 계정으로 무중단 전환하는 공식 공개 API는 이번 조사에서 확인하지 못했습니다. 미터기는 기존의 `Codex 종료 확인 → 선택 인증 적용 → 재실행` 구조를 유지합니다. 공식 로그인/사용량 인터페이스와 Windows 패키지 식별을 사용해 변경 영향을 줄였지만, 인증 저장 방식이나 지원 API가 바뀌면 추가 대응이 필요할 수 있습니다. 영구 무유지보수나 모든 기기에서 매번 성공을 보장하지 않습니다.

실제 계정 전환은 진행 중인 Codex 작업을 중단하므로 작업이 끝난 시점에 확인하세요. 이 릴리스 준비 과정에서는 사용자의 실제 계정 전환을 수행하지 않았습니다.

## 업데이트

`⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작`으로 업데이트한 후 v1.0.9를 확인하세요. 기존 연결/계정/설정은 그대로 사용합니다. 계정 전환은 미터기에서 평소와 같이 한 번 누르시면 됩니다. 실패하면 미터기 오류 문구와 `%LOCALAPPDATA%\CodexUsageMeter\account-switch.log`의 해당 시각 기록으로 구간을 구분할 수 있습니다.
