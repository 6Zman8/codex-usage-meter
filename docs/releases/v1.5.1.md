# v1.5.1 — 편집창 최대화·확대축소와 기본 간격 개선

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작** 후 **배치 편집창 오른쪽 위 □**를 누르세요. 제목 표시줄을 더블클릭해도 최대화하며, 다시 누르면 이전 위치·크기로 돌아갑니다.

- 미리보기의 **− / +**와 **Ctrl+마우스 휠**로 25~400% 확대·축소합니다. **100%**는 실제 크기, **화면에 맞춤**은 편집 영역에 맞게 크기를 조절합니다. 큰 창에서는 위젯 미리보기도 확대됩니다.
- 확대해서 화면 밖으로 나간 카드는 가로·세로 스크롤로 접근합니다. 마우스 휠 확대는 포인터 아래 내용을 기준으로 하며 편집 손잡이도 같은 배율을 따라갑니다.
- 보기 배율은 저장된 카드 크기와 위치를 바꾸지 않습니다. 항목 자체의 크기는 기존 **항목 편집 → ◢**로 조절하고 **배치 저장**으로 반영합니다.
- 기본 위젯의 게이지·갱신 시간 간격을 넓히고, 고정 폭으로 가운데에 몰리던 내용을 카드 폭에 맞춰 분산합니다. 전체 화면의 한도·초기화권·통계·달력 사이 여백과 PC 지표 간격도 넓혔습니다.
- 기존 배치 설정과 계정·이력을 유지합니다. 기본 간격 개선은 직접 배치하지 않은 항목에 자동 적용되며, 직접 저장한 위치·크기는 유지합니다.

검증: 최대화·이전 위치/크기 복원·제목 더블클릭, 보기 배율·한계값·스크롤·연속 휠의 포인터 기준 확대, 확대 중 항목 이동·손잡이 정렬, 작은 편집창의 조작 버튼과 좁은 카드·글씨 배율·기존 저장 배치 보존을 숨김 WPF 표면에서 확인했습니다. 공개 실행파일의 전체 검사 72개와 계정 전환 검사 13개, v1.5.0의 내장 업데이트 다운로드 검증도 통과했습니다. [검증 기록](v1.5.1-verification.md)을 참고하세요.
