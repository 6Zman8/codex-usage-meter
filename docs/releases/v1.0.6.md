# Codex Usage Meter 1.0.6

Codex 재연결 시 앱이 종료된 뒤 다시 열리지 않던 문제를 수정했습니다.

- 종료 직후 프로세스를 조회할 때 발생하는 Windows 오류를 실제 종료 여부로 다시 확인합니다.
- 종료 확인에 실패해도 계정 정보를 유지하고 기존 계정으로 Codex를 다시 여는 복구를 시도합니다.
- 현재 계정에서도 `재연결`을 눌러 Codex를 다시 열 수 있습니다.
- 계정 전환 중 미터기와 미터기용 연결을 보호하고, 더 최신인 인증정보를 보존합니다.
- Codex 창과 내부 연결 프로세스가 안정적으로 시작되는지 확인하고, 시작 실패 시 복원 순서를 개선했습니다.
- 로그인·연결 해제가 대기 중일 때 계정 페이지를 넘겨도 처음 선택한 계정에 적용됩니다.

기존 사용자는 미터기의 `⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작`으로 업데이트할 수 있습니다. 처음 사용하는 경우 이 릴리스의 `CodexUsageMeter.exe`를 내려받아 더블클릭하세요.
