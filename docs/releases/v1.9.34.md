# v1.9.34

- **공용 네트워크도 버튼 한 번으로 해결합니다.** 폰 리모컨이 "네트워크가 '공용'으로 설정돼 있어 폰이 연결할 수 없습니다"라고 할 때, 이제 **개인 네트워크로 바꾸고 방화벽 허용 (관리자 승인 1회)** 버튼이 나옵니다. 누르고 관리자 승인 창에서 '예'를 누르면 폰 등록 QR에 들어간 연결 하나만 '개인 네트워크'로 바꾸고 방화벽 허용까지 끝냅니다(다른 연결은 그대로). 집 와이파이에서만 쓰세요.
- 직접 바꾸고 싶으면 **Windows 네트워크 설정 열기** 버튼을 누르세요. 유선이면 이더넷, 와이파이면 Wi-Fi 설정 페이지가 바로 열립니다(Wi-Fi는 연결 이름의 '속성'에서 바꿉니다). 공용 상태에서는 10초마다 다시 확인하므로, 설정에서 바꾸면 미터기 화면도 곧 바뀝니다.

검사:
- `--phone-remote-self-test`: 방화벽만 막혔을 때는 기존 버튼만 나오고 네트워크를 건드리지 않으며, 공용 네트워크일 때는 두 버튼이 나오고 설정 바로가기와 허용 버튼이 등록 주소의 연결을 대상으로 하는지, 허용 뒤 화면이 갱신되는지 확인합니다. 관리자 명령 문자열도 확인합니다.
- 이 PC(이미 개인 네트워크)에서 같은 관리자 명령으로 해당 연결을 'Private'으로 지정하면 성공(종료 코드 0)하고 상태가 그대로이며, 없는 연결 번호는 실패(1)로 보고되는 것을 확인했습니다.
- 확인하지 못한 것: 실제 공용 네트워크 PC에서 바꾸는 과정, 설정 바로가기가 여는 화면(창을 띄우지 않았음).
