# v1.9.2

- 위젯 계정 카드에 추가된 일반 재연결 버튼을 완전히 제거합니다. 이름만 바꾸거나 숨기는 방식이 아닙니다.
- 이력 버튼과 원래 맨 오른쪽 Codex 버튼의 재연결·전환 표시 및 동작은 그대로 유지합니다.
- 인증됨·미연결·보관된 인증 상태 모두 위젯에서 일반 계정·공급자 로그인을 시작하지 않습니다. 일반 연결·다시 로그인·공급자 선택은 전체 화면에서 계속 제공합니다.
- 기존 계정 자료·이력·저장 배치를 보존합니다.

정식 게시 후 사용 경로: **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**. Windows 위젯 사용자는 **Windows 위젯 추가 / 업데이트**도 실행하세요.
