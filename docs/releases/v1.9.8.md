# v1.9.8

- 전체 화면·위젯에서 이력을 열면 기존 카드 제목·버튼과 본문을 함께 숨겨 이력 조작부와 겹치지 않도록 수정했습니다.
- 계정 및 PC 이력에 원래 카드와 같은 불투명 배경을 적용했습니다.
- `← 현재`와 배치 편집 전환 시 원래 화면을 복원하며, 저장된 제목 위치·숨김 설정은 변경하지 않습니다.
- 숨김 WPF 검사에서 양 모드·계정 두 칸·PC 이력, 100~200% 글씨, 작은 창, 빈 이력, 실제 클릭 대상, 배치 편집과 복원을 검사합니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
