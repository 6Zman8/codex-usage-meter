# v1.2.2 — 웹 ChatGPT 구독 연결

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 업데이트합니다. 각 계정의 **초기화권 아래 구독 날짜**를 클릭한 뒤 웹 ChatGPT에 해당 계정으로 로그인하세요. 날짜를 확인하면 창이 닫힙니다.

- 정상 웹 로그인으로 조회한 구독 갱신일·종료일을 표시합니다. Codex 사용량 인증의 결제 조회가 403이어도 별도 웹 연결을 사용할 수 있습니다.
- 예약된 플랜 변경은 날짜와 다음 플랜을 함께 표시합니다. 현재 Pro 이용 후 Plus로 전환되는 경우를 단순 Pro 갱신으로 표시하지 않습니다.
- 최초 연결 이후 6시간마다 백그라운드로 확인합니다. 실패 시 1시간 간격으로 재시도하며, 24시간을 넘긴 날짜는 현재 정보로 사용하지 않습니다.
- 계정 ID·현재 플랜을 확인하고, 조회 도중 계정이 바뀌면 결과를 버립니다. Chrome·Codex 인증이나 쿠키를 가져와 복사하지 않습니다.
- 전체·위젯의 기존 카드 배치, 5시간 한도 자리, 스크롤 없는 맞춤 배치를 유지합니다.

## 검증 범위

- 실제 로그인된 Chrome 결제 화면과 계정 응답에서 플랜 전환 날짜가 일치함을 확인했습니다. 미터기 계정과 식별자를 대조한 뒤 날짜만 로컬 캐시에 반영했습니다. 이 캐시는 미터기의 웹 로그인 연결을 대신하지 않습니다.
- 격리된 숨김 WebView2의 정상 페이지 요청 → 응답 수집 → 날짜 저장 → 종료 → 재실행 검사, 계정·플랜 변경과 24시간 만료 검사, 전체·위젯 UI 및 계정 전환 회귀검사를 수행했습니다.
- 실제 WebView2는 익명 ChatGPT 로그인 화면까지 확인했습니다. 사용자가 최초 로그인한 뒤 인증 세션을 유지하며 자동 확인하는 경로는 아직 실제 계정으로 검증하지 않았습니다. 로그인 공급자나 추가 보안 확인에 따라 직접 조작이 필요할 수 있습니다.
- 실제 사용자 Codex 전환·종료나 기존 미터기 강제 교체는 수행하지 않습니다. 다른 PC의 로그인 상태는 별도로 확인해야 합니다.

빌드에는 Microsoft WebView2 SDK 1.0.4258.31의 Core 어셈블리와 네이티브 로더를 포함합니다. 버전과 패키지 SHA-256을 고정하고 라이선스를 실행파일에 내장합니다. Runtime은 PC 설치본을 사용합니다.
