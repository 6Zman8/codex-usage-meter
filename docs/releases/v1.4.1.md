# v1.4.1 — 계정별 잔여량 이력 그래프

## 목표와 보존

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작** 후 계정 카드의 **이력**을 누르세요. 새 창 없이 해당 카드 내용이 단기·주간 잔여량 그래프로 바뀌고 **← 현재**로 돌아옵니다. 전체 화면과 위젯 모두 지원하며 다른 카드의 위치와 크기를 유지합니다.

민트색 단기·보라색 주간 선을 실제 시간축과 0~100% 축에 표시합니다. 선과 점에 마우스를 올리면 확인 시각·잔여 비율·예정 초기화·플랜을 보여 줍니다. 2분을 넘는 관측 공백, 초기화·플랜·한도 변경과 값 증가는 선을 끊습니다. 단일 기록은 점으로 표시하며 결측은 0%로 만들지 않습니다.

보기 목록에서 **기록 표 / 초기화 전**으로 전환합니다. 기존 기록과 초기화 전 마지막 확인값, 계정·기간 선택, 저장 파일 형식은 유지합니다. 실행 중인 미터기와 Codex, 인증·계정 자료는 변경하지 않습니다.

## 체크포인트

- 조사 완료: v1.4.0 저장 기록을 그대로 사용하며 별도 차트 라이브러리 없이 WPF로 표시합니다.
- 구현 완료: 카드 내부 화면 전환, 시간축·0~100% 축, 단기/주간 색 구분, 기록 공백·초기화 경계 구분, 마우스 확인값, 표 전환.
- 기능 검증: 이력 검사 20개 통과. 카드 크기와 다른 카드 배치 보존, 돌아가기, 계정/페이지 변경, 시간 간격, 누락/0%/단일 기록, 기간 경계, 보통·작은 카드 렌더를 검사했습니다.
- 남은 단계: 최종 빌드 회귀검사, 정식 Release 및 이전 버전 내장 업데이트 검증.
- 완료 조건: 검증된 정식 Release와 내장 업데이트 경로, 프로젝트 최종 실행파일과 검사 자료 보관.
