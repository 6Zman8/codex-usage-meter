# v1.8.3

- 배치 편집창과 미터기의 최대화·복원을 Windows 작업영역의 픽셀 좌표로 처리합니다. WPF 좌표와 WinForms 화면 좌표 사이의 중간 배율 변환을 제거했습니다.
- 최대화 결과가 모니터 작업영역의 네 모서리와 정확히 일치하는지 검사합니다. 기존 검사의 “창이 커졌다/영역 안에 있다” 조건을 대체합니다.
- 숨김 창의 배율 컨텍스트별 최대화·복원과 4K·100/150/200%에 해당하는 작업표시줄 크기, 음수/보조 모니터 좌표를 검사합니다. 좌표 모의검사는 실제 디스플레이 설정 변경과 구분합니다.
- 저장 배치·카드 크기·순서·숨김·설정과 계정·인증 자료의 형식이나 값은 변경하지 않습니다.

## Windows 위젯 목록 미표시

제공된 v1.8.1 진단은 Windows 11 빌드 26200, Web Experience Pack 526.21100.40.0에서 패키지/확장 등록과 런타임 검사가 통과했음을 보여 줍니다. 설치 진행 CLIXML은 오류가 아닙니다. 확장 정의는 Microsoft 공식 manifest 예제 및 C# 샘플과 비교했으며, 보드 목록 미표시를 설명할 차이는 확인하지 못했습니다.

이 패치는 위젯 목록 미표시를 해결했다고 주장하지 않습니다. 실제 노트북 위젯 보드의 인식/표시와 최대화 결과는 현장 확인이 필요합니다. 실행 앱 종료·위젯 보드 초기화·등록 삭제·개발자 모드 변경을 하지 않습니다.

## 배포 이력

v1.8.2는 CI의 4K 모의검사 실패로 Release를 게시하지 않았습니다. WPF가 작은 검사 화면의 최대 창 크기로 모의 4K 창을 제한하는 것이 원인이었습니다. 실제 모니터 최대화 검사는 그대로 두고, 모의검사에만 4K에 맞는 창 크기 제한을 지정했습니다. 실패한 태그를 덮어쓰지 않고 v1.8.3으로 배포합니다.

배치 보존 검사에서도 JSON 속성 순서만 달라진 데이터를 변경으로 오인하는 문제가 드러났습니다. 저장값을 고치는 대신, 검사에서 전후 배치의 같은 스키마를 같은 방식으로 직렬화해 비교합니다.
