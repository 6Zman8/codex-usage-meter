# v1.9.1

- 기본 카드 제목·계정 정보는 왼쪽, 조작 버튼은 오른쪽에 정렬합니다.
- 위젯에서 신규 연결을 제거하고 전체 화면에서만 제공하며, 기존 계정의 재연결·전환은 유지합니다. 인증이 만료되어도 보관된 연결 정보가 있으면 재연결할 수 있습니다.
- PC 상태의 이력 버튼과 LIVE 표시는 오른쪽에 배치합니다. 그래프 영역만 축소해 제목줄이 중앙으로 밀리지 않도록 수정합니다.
- 배치 편집의 기본 미리보기는 현재 창의 실제 내용 크기를 사용하고, 그래프 눈금·점선을 실제 카드와 동일하게 표시합니다.
- 기존 저장 배치·숨김·계정 자료를 보존합니다.

사용 경로: **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**. Windows 위젯 사용자는 **Windows 위젯 추가 / 업데이트**도 실행하세요.

검증: 숨김 배치 검사에서 정렬, 신규 연결 제한, 가짜 제공자를 통한 정상·인증 만료 재연결, 실제/미리보기 눈금 일치, 기존 배치 보존을 확인했습니다. 실계정 로그인·다른 PC 확인은 수행하지 않았습니다.
