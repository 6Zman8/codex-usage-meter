# v1.9.35

- **꾹 누르는 시간을 1.2초에서 0.6초로 줄였습니다.** PC 미터기의 **화면 끄기**·**절전** 버튼과 폰 **PC 리모컨** 앱(1.0.2) 모두 0.6초 동안 게이지가 차고, 다 찬 뒤 손을 떼면 실행됩니다. 중간에 떼면 취소되는 방식은 그대로입니다.
- 폰 앱은 열 때 1.0.2 업데이트를 알립니다.

검사:
- 미터기: 전원 버튼 회귀 검사(게이지 진행, 일찍 떼면 취소, 다 찬 뒤 손을 뗄 때 한 번만 실행, Space 키)를 0.6초 기준으로 통과했습니다.
- 앱: 단위 검사와 정식 서명 빌드(`releaseAssets`, 1.0.2·versionCode 3)가 통과했습니다. 숨김 Android 17 에뮬레이터 전체 시나리오(디버그 빌드, 시험 서버 대상)에서 2초 누르면 한 번 실행, 0.25초 누르면 아무것도 보내지 않음, 앱 내 업데이트까지 통과했습니다. 검사 스크립트가 앱 버전을 1.0.0으로 고정해 두었던 부분은 `version.properties`에서 읽도록 고쳤습니다.
