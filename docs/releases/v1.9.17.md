# v1.9.17

- **크롬 구독 연결이 업데이트 후 멈추던 문제 수정**: 업데이트로 미터기가 다시 시작될 때 이전 미터기가 잠깐 포트(127.0.0.1:43129)를 붙잡고 있으면, 새 미터기가 크롬 연결 창구를 열지 못한 채 다시 시도하지 않았습니다. 그래서 크롬에서 claude.ai·ChatGPT 결제 페이지를 열어도 구독 날짜가 반영되지 않았습니다. 이제 열릴 때까지 1분마다 다시 시도합니다.
- **Claude 사용량 이력이 저장되지 않던 문제 수정**: 업데이트 중 두 미터기가 겹쳐 같은 시각의 기록이 두 번 남으면, 이력 파일을 손상된 것으로 보고 이후 저장과 통계 표시를 모두 거부했습니다. 같은 시각의 기록은 정상으로 처리합니다. 기존 기록은 그대로 이어집니다.
- **Claude Code 없이 사용 가능함을 명확히**: Claude Code가 설치되지 않은 PC에서는 Claude 카드의 **전환** 버튼이 비활성화되고, "Claude Code를 쓰는 경우에만 필요한 기능"이라는 안내가 표시됩니다. 사용량·초기화권·구독 날짜 표시에는 Claude Code가 필요 없습니다.

검사: 사용량 이력·공급자·배치·크롬 구독·계정 전환·위젯·전체 자체 검사를 통과했고, 실제 Claude 이력 파일 복사본이 정상으로 읽히는 것을 확인했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
