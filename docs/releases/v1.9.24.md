# v1.9.24

- **Claude 요청 제한 줄이기**: Claude 사용량 조회 한도는 같은 계정을 쓰는 모든 프로그램이 함께 씁니다. 이제 같은 PC의 Mixdog이 이미 받아 둔 Claude 사용량이 같은 계정의 값으로 확인되면, 미터기는 따로 요청하지 않고 그 값을 보여 줍니다.
  - 같은 계정인지는 미터기가 직접 받은 값과 Mixdog 값이 2분 안의 시각에 일치할 때만 연결합니다. 주간·5시간 초기화 시각이 맞지 않거나, 같은 계정일 수 있는 Mixdog 계정이 둘 이상이면 쓰지 않습니다.
  - Mixdog 값을 쓰는 동안에도 10분마다 한 번은 미터기가 직접 확인합니다.
- **요청 제한 뒤 대기 단축**: 요청 제한에 걸리면 2분부터 두 배씩 최대 10분까지 기다립니다(이전 5분~60분). 제한 뒤 30분 동안은 약 3분 간격으로만 직접 조회합니다.
- **제한 중에도 값 표시**: 요청 제한으로 기다리는 동안 위젯과 트레이도 마지막 값을 계속 보여 주고 `요청 제한 대기`를 표시합니다. 이전에는 `조회 실패`나 `--`로 바뀌었습니다.

다른 PC에서 실행 중인 Mixdog의 요청은 줄일 수 없습니다. 여러 PC에서 같은 계정을 동시에 쓰면 제한이 걸릴 수 있지만, 그때도 마지막 값은 계속 보입니다.

검사: 전체 자체 검사(`--self-test`)와 공급자 검사(`--provider-self-test`)를 통과했으며, Mixdog 값 연결·거부와 제한 중 표시 검사를 추가했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
