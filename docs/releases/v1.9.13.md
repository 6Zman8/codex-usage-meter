# v1.9.13

Claude 카드에 GPT/Codex 카드와 같은 항목이 표시됩니다.

- **초기화권**: Claude의 한도 초기화(Reset for free) 보유 개수와 가장 빠른 만료일을 표시합니다.
- **구독 날짜**: Claude 구독의 다음 결제일 또는 종료일을 GPT와 같은 자리에 표시합니다.
- **사용 통계**: 누적, 최고 일간, 연속 사용일, 월 달력, 최근 7일 그래프를 주간 한도 %로 표시합니다. Claude는 토큰 수를 제공하지 않아, 미터기가 기록한 사용량 이력으로 계산합니다. 미터기가 기록하기 시작한 날부터 채워집니다.
- **모델별 비율**: 최근 7일 동안 모델별로 주간 한도를 얼마나 썼는지 표시합니다.

## 사용 방법

초기화권과 구독 날짜는 claude.ai 웹 로그인이 한 번 필요합니다.

1. Claude 카드에서 밑줄 친 **구독 날짜 · claude.ai 연결하기**를 누릅니다. **연결 ▾ → claude.ai 웹 연결 (초기화권·구독 날짜)**로도 열 수 있습니다.
2. 열린 창에서 그 칸의 Claude 계정으로 로그인합니다. 확인이 끝나면 창이 저절로 닫힙니다.

이후에는 3시간마다 보이지 않게 다시 읽습니다. 웹 로그인 계정이 그 칸의 Claude 계정과 다르면 값을 저장하거나 표시하지 않습니다.

## 검사

공급자, 배치, 웹 구독, 사용량 이력, 트레이, Windows 위젯, 계정 전환, 전체 자체 검사를 통과했습니다. claude.ai 웹 응답 형식은 공개 자료를 기준으로 구현했으며, 실제 로그인 확인은 배포 후 진행합니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
