## 보존과 한계

사용 중인 Codex를 종료하거나 실제 계정을 전환하지 않았습니다. 초기화 경계·플랜 전환·조회 실패·손상 격리는 가상 시각/자료로 시험했습니다. 실제 계정의 다음 초기화 및 다른 PC 실행은 아직 관측하지 않았습니다. 이력은 새 버전 실행 후 성공한 관측부터 쌓이며, 과거의 미관측 값은 복원하지 않습니다.

로컬 검사 기록과 필요한 가상 검사 자료는 프로젝트의 `artifacts/usage-history-v1.4.0`에 보관합니다. 여기에 실제 이메일·계정 ID·인증 토큰·대화는 기록하지 않았습니다. 이력 데이터와 로그인 자료는 Git에 포함하지 않았습니다.

최종 실행파일과 필요한 최종 검사 자료를 보존한 뒤, 이번 작업의 중복 검증 실행파일·불필요한 가상 검사 중간자료 20개를 휴지통으로 이동했습니다. 원래 위치에서 사라진 것과 휴지통 복구 메타데이터를 확인했으며, 휴지통을 비우지 않았습니다.
