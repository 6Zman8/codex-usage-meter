# v1.2.0 — 눈으로 편집하는 배치와 구독 갱신일

프로그램의 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 설치합니다.

- **배치 편집:** 실제 대시보드를 보며 카드 위쪽을 끌어 순서를 바꾸고 오른쪽 아래 손잡이로 폭·높이를 조절합니다. 전체 화면과 위젯을 탭으로 오가며 각각 저장합니다. 왼쪽에서 카드·표시 항목·열 수를 선택하며, 다른 페이지의 계정도 선택 즉시 보여 줍니다. 취소하면 두 화면 모두 원래 배치로 돌아갑니다.
- **구독 갱신일 카드:** 서비스 이름·기준일·매월/매년/한 번 주기를 직접 등록하면 다음 날짜와 남은 일수를 표시합니다. 월말과 윤년을 처리하고 지난 일회성 일정은 경과일로 표시합니다. 배치 편집에서 카드를 켜고 `구독 서비스·갱신일 관리`로 등록합니다.
- **다크 UI:** 대시보드·설정·편집창·구독 관리의 스크롤바와 입력 컨트롤을 어두운 테마로 맞췄습니다.
- **한도별 크기 보정:** 단기 한도가 없는 계정은 주간 게이지와 갱신 정보를 남은 폭에 맞춰 표시합니다. 같은 행에서 같은 높이를 선택한 카드의 외곽 높이를 맞추며, 개별 높이 선택은 유지합니다.

기존 계정 연결과 저장한 배치는 유지됩니다. 구독 카드는 처음에는 숨겨져 있으며, 구독 목록은 전체와 위젯이 공유합니다. 날짜는 직접 입력한 주기에 따른 예정일이며 실제 결제 내역을 조회하지 않습니다.

## 검증 범위

가상 계정과 숨김 WPF 화면에서 실제 카드 렌더링·드래그 이벤트·크기 손잡이·스크롤·모드/창 크기/계정 페이지 전환·저장/취소·오류 시 화면 복원을 검사합니다. 작은 창, 글자 100~200%, 월말·윤년·지난 날짜, 손상된 설정 복원도 포함합니다. 기존 계정 전환·한도 표시·업데이트 안내 검사를 함께 실행합니다. 실제 사용자 계정 전환이나 기존 앱 종료는 검사에 사용하지 않습니다.
