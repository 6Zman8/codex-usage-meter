# v1.9.28

v1.9.27 태그는 배포 검사에서 멈춰 Release 파일이 게시되지 않았습니다. 같은 기능을 이 버전으로 게시합니다.

- **화면 끄기·절전 큰 버튼**: 전체 화면은 오른쪽 기둥(버튼 하나 약 250×341), 위젯 화면은 아래쪽 띠(버튼 하나 약 224×124)에 두었습니다. 폰으로 원격 접속해도 손가락으로 누를 수 있는 크기입니다. 창이 작아지면 버튼도 비율에 맞춰 줄어듭니다.
- **꾹 눌러서 실행**: 확인창 없이, 1.2초 동안 누르고 있으면 게이지가 찹니다. 끝까지 차기 전에 손을 떼거나 버튼 밖으로 벗어나면 게이지가 비워지고 아무 일도 일어나지 않습니다. 끝까지 차면 확정되어 취소되지 않고, 손을 떼는 순간 실행됩니다. 누른 채로 끄면 손을 떼는 입력 때문에 화면이 바로 다시 켜질 수 있어서입니다.
- 화면 끄기는 모니터만 끄고(마우스·키보드를 움직이면 다시 켜짐), 절전은 PC를 대기 모드(S3)로 보냅니다. 절전에 실패하면 아래 상태줄에 이유를 표시합니다.
- 누르는 도중 창이 바뀌는 등으로 눌림이 끊기면, 다 차기 전에는 취소하고 다 찬 뒤에는 실제로 손을 뗄 때까지 기다렸다가 실행합니다. 마우스로 누른 것은 마우스를, 스페이스로 누른 것은 스페이스를 떼야 끝나며, 손을 뗀 시각으로 다 찼는지 판단합니다.
- 터치로 길게 눌러도 오른쪽 클릭으로 바뀌지 않게 했습니다. 구글 도움말에 따르면 크롬 원격 데스크톱 기본(트랙패드) 모드에서는 회색 원이 뜰 때까지 누르면 그때부터 누른 상태가 됩니다. 실제 폰에서는 아직 확인하지 않았습니다.
- Windows 위젯 보드(Win+W) 그림에는 전원 버튼을 넣지 않습니다.

검사: 배치 검사(`--layout-self-test`)에 실제 버튼 이벤트(눌림 상태·마우스·스페이스·캡처 손실)를 거치는 누르기 동작(일찍 떼기·벗어나기 취소, 늦게 처리된 이른 떼기 취소, 다 찬 뒤 실제로 손 뗄 때 한 번만 실행)과 전원 버튼 크기·클릭 가능 여부(전체 1280×820, 위젯 476×591, 좁은 창)를 추가했습니다. 전원 버튼이 차지한 공간만큼 기존 배치 검사의 카드 폭·위젯 높이 기준을 맞췄습니다. 실제 화면 끄기·절전 실행은 자동 검사에 포함하지 않습니다.

배치 저장 내용을 비교하는 검사가 가끔 실패하던 원인도 고쳤습니다. 저장 JSON의 속성 순서는 .NET이 실행마다 보장하지 않는데 글자 그대로 비교하고 있었습니다. 이제 순서와 무관하게 비교하며, 앱의 저장·불러오기 동작은 바뀌지 않았습니다.
