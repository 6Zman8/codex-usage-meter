# v1.9.21

- **계정 순서가 칸 수와 무관하게 유지**: v1.9.20에서는 계정 칸 수를 줄이면 칸 밖의 계정이 순서에서 빠져 목록이 원래대로 돌아갔습니다. 이제 **⚙ 설정 → 계정 순서**에 4개 칸이 모두 나오고, 계정 칸 수는 그 순서의 위에서부터 n개를 보여 줍니다. 칸 밖 계정은 "표시 안 함"으로 흐리게 나오며, ▲로 올리면 칸 안으로 들어와 바로 조회됩니다. 칸 밖의 GPT/Codex 계정은 저장된 로그인에서 이메일을 읽어 구분할 수 있게 했습니다.
- **창 크기·위치 기억**: 위젯 화면과 전체 화면의 창 크기·위치를 각각 저장해 다음 실행 때 그대로 엽니다. 저장한 위치의 모니터가 연결되어 있지 않으면 기본 위치로 엽니다. 최대화 상태는 저장하지 않고 최대화 전 크기를 기억합니다.

검사: 전체 자체 검사(`--self-test`)와 배치·위젯·계정 전환·업데이트 화면 검사를 통과했습니다. 칸 수를 넘는 순서 이동·상위 n개 표시·창 위치 값 읽기 검사를 추가했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
