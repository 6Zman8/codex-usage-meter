# v1.9.4

- 제목줄을 본문 비율 맞춤에서 분리하여 높이 축소 시 가로 배치를 보존합니다.
- 저장 제목줄의 영역은 기존 좌표·크기를 그대로 적용하며, 내부 Grid가 폭에 맞춰 제목과 버튼을 배치합니다. 저장 영역이 고유 높이보다 짧으면 내부 요소는 고유 높이를 사용하여 조작 영역이 잘리지 않도록 합니다.
- 기본·전체 저장·제목줄이 없는 부분 저장 배치, 계정·PC, 전체·위젯 모드, 320·460·900 폭과 100·200% 글씨에서 820→620→480→320→820 높이 변경의 실제 경계·본문 버튼 조작과 저장값 무변경을 검사합니다.
- 실제 크기 미리보기는 320·460·900 폭, 320·480·780 높이에서 기본·전체·부분 저장 배치의 표시·저장·복원을 비교합니다.
- Windows 위젯의 작은 이미지용 `FitNaturalContent` 경로는 전체 자연 크기 맞춤을 유지합니다.

- 제목줄과 사용 가능한 본문 높이가 부족한 극소 높이에서는 카드 전체 바깥에 세로 스크롤바를 표시합니다. 스크롤로 본문 조작 영역에 접근하며, 스크롤바 공간은 항상 확보하여 제목줄의 가로 위치가 바뀌지 않습니다. 일반 높이의 유한 높이 맞춤과 저장 좌표는 유지합니다.

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 적용합니다.
