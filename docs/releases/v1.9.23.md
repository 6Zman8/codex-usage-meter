# v1.9.23

- **새로고침 즉시 반영**: 새로고침 버튼을 누르면 마지막 조회 후 50초가 지나지 않았어도 Claude 사용량을 바로 다시 받아옵니다. Claude가 요청 제한(429)으로 기다리라고 한 시간은 계속 지킵니다.
- **요청 제한 대기 표시**: Claude 요청 제한으로 대기 중이면 작은 카드의 계정 줄에 `요청 제한 대기 · HH:mm 이후 재확인`을 표시합니다. 이전에는 마우스를 올려야만 보였습니다.

검사: 전체 자체 검사(`--self-test`)와 업데이트 화면 검사를 통과했으며, 수동 새로고침 재조회 검사를 추가했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
