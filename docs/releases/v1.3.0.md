# v1.3.0

- 구독 날짜를 누르면 평소 Chrome과 Tampermonkey를 연결합니다. 저장된 Chrome 로그인·비밀번호를 그대로 사용하며 내장 브라우저에 다시 로그인하지 않습니다.
- 연결 스크립트를 처음 한 번 설치하고 미터기의 `크롬 열기`으로 연결하면, 이후 ChatGPT 구독 페이지 방문 때 해당 계정의 날짜를 반영합니다.
- Chrome을 닫은 동안 새 날짜를 확인하지 않습니다. 마지막 확인이 오래됐거나 날짜가 지나면 `재확인 필요`와 확인 시각을 제공합니다.
- 계정/플랜 검증, 로컬 전용 연결 키, 응답 필드 제한과 수신 크기 제한을 적용합니다. 기존 인증·계정·내장 웹 세션을 보존합니다.
- Chrome 연결 이후 지연된 내장 웹 응답이나 더 오래된 동시 수신이 최신 날짜를 덮지 못하도록 했습니다.

사용 순서: `⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작` 후 초기화권 아래 구독 날짜 → `스크립트 설치` → 설치 → 날짜 다시 클릭 → `크롬 열기`.

실제 Tampermonkey 설치·로그인된 Chrome과 앱 사이의 최종 연결은 자동화의 확장 페이지 접근 제한으로 미확인입니다. 기존 앱은 강제 종료하거나 교체하지 않습니다. 격리 검사와 실사용 확인을 구분합니다.
