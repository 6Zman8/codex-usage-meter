# v1.9.22

- **작은 창에서 닫기 버튼이 눌리지 않던 문제 수정**: 오른쪽 위 구석의 크기 조절 영역(30×30)과 테두리 조절 영역(12px)이 닫기 버튼을 덮고 있었습니다. 이제 오른쪽 위 구석에서는 가장자리 4px만 테두리 조절, 맨 끝 6×6만 모서리 조절로 동작합니다. 다른 세 모서리와 테두리는 그대로입니다.

검사: 전체 자체 검사(`--self-test`)와 업데이트 화면 검사를 통과했으며, 오른쪽 위 조절 영역 검사를 추가했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
