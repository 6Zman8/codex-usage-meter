# v1.8.4

- PC 상태 기본 화면을 공유 눈금·기준선 위의 세로 막대 그래프로 변경했습니다. 선택한 [WireStack의 System metrics](https://wirestack.nyoncode.cz/core/widgets/charts/#system-metrics-vertical-with-grid-lines) 구성을 참고하고 기존 미터기의 다크 톤과 CPU·GPU·RAM·디스크 색상을 유지합니다. 외부 화면 이미지나 코드는 앱에 포함하지 않습니다.
- 항목명 → 사용률 → 막대 순서로 배치하며, 각 지표를 별도 네모 카드로 감싸지 않습니다.
- 수치 자리를 `100%` 기준으로 확보합니다. `9% ↔ 10% ↔ 100%`, 미감지 `N/A`, 장치 번호 변화 때문에 막대·항목·조절박스가 확대·축소되지 않습니다.
- 저장 배치의 좌표·크기·순서·숨김을 초기화하거나 자동 재정렬하지 않습니다. 직접 재배치해 막대의 높이·기준선이 달라진 경우에는 맞지 않는 공유 눈금을 표시하지 않습니다.
- 미터기 위젯모드와 Windows 위젯은 같은 렌더링을 사용합니다.
- 설치된 앱의 교체·재시작은 사용자가 내장 업데이트에서 실행합니다. Windows 위젯 보드의 목록 미표시는 이 버전에서 해결됐다고 주장하지 않습니다.
