# v1.9.26

- **배포 때 자동 설치**: 실행 중인 미터기가 `CodexUsageMeter.exe --install-update` 요청을 받으면 안내창 없이 최신 버전을 확인·다운로드·SHA-256 검증한 뒤 교체하고 다시 시작합니다. 트레이·최소화·최대화 상태와 전체/위젯 화면을 그대로 유지한 채 다시 시작합니다. 계정 전환·업데이트·배치 편집 중에는 요청을 건너뜁니다.
- **업데이트 실패 시 복구**: 교체에 실패하면 기존 버전을 원래 상태로 다시 켭니다. 자동 설치에서는 안내창도 띄우지 않습니다. 이전에는 일부 실패에서 미터기가 꺼진 채로 남을 수 있었습니다.
- 수동 업데이트와 자동 설치가 동시에 진행되지 않도록 막았습니다.
- 이 버전부터 새 버전이 배포되면 작업자가 설치본까지 바로 업데이트할 수 있습니다.

검사: 전체 자체 검사(`--self-test`), 단일 실행 검사(`--single-instance-self-test`)를 통과했으며, 설치 요청이 창을 띄우지 않고 실행 중인 미터기에 전달되는지와 교체 프로그램의 재시작 옵션 검사를 추가했습니다.

이번 버전은 제목줄의 **⬆ 업데이트** 버튼(또는 ⚙ 설정 → 업데이트 확인)으로 받으세요. 다음 버전부터는 자동으로 설치됩니다.
