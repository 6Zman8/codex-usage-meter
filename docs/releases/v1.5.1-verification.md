검사 자료는 `artifacts/editor-zoom-v1.5.1`에 보관합니다. 이전 최종 실행파일 v1.5.0은 SHA-256을 확인해 복구본으로 보존했습니다. 최신 가상 검사 자료와 최종 파일을 남긴 뒤 이번 작업의 중복 EXE 2개와 중간 가상자료 폴더 2개를 휴지통으로 이동하고 원래 위치 제거·복구 가능성을 확인했습니다. 휴지통은 비우지 않았습니다.

사용 경로는 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작 → ⚙ 설정 → 배치 편집**입니다. **오른쪽 위 □ 또는 제목 더블클릭**으로 최대화하고, **− / +·100%·화면에 맞춤·Ctrl+휠**로 미리보기를 조절합니다. 실행 중인 설치본 v1.5.0과 Codex 세션은 보존했습니다. 다른 PC, 서로 다른 DPI 모니터 사이의 실제 창 이동, 실제 계정 전환은 수행하지 않았습니다.
