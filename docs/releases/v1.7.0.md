# v1.7.0

기존 미터기에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요. 별도 실행파일로 바꿀 필요가 없습니다.

- **배치 편집 → 항목 편집**에서 제목·게이지·갱신 시간·구독 날짜·PC 지표 등을 개별로 숨기고 다시 표시할 수 있습니다. 숨긴 항목은 편집 목록에 남으며, 계정별·전체/위젯별로 저장됩니다. 취소하면 이전 배치로 돌아갑니다.
- **Windows 위젯**은 미터기 위젯모드와 같은 화면 구성과 저장된 카드 순서·요소 위치·크기·숨김을 반영합니다. 작은 크기에서는 카드를 넘겨 봅니다. Windows가 관리하는 제목줄·메뉴는 그대로이며, 본문은 공통 화면을 그린 이미지입니다. 화면 클릭은 미터기를 열고 새로고침·다음 계정은 위젯 버튼으로 동작합니다.
- **⚙ 설정 → 트레이 잔여량 표시**에서 계정과 단기·장기 한도를 선택하면 시계 옆에 남은 %가 표시됩니다. 한 번 클릭하면 미터기가 열리며, 설정은 재실행 후에도 유지됩니다. 조회 전·오류·갱신 대기·미제공 한도는 `--`, 실제 0%는 `0`으로 구분합니다.

Windows 위젯을 이미 사용 중이면 본체 업데이트 후 **⚙ 설정 → Windows 위젯 추가 / 업데이트**도 눌러 제공자를 갱신하세요. 최초 등록 조건은 [Windows 위젯 안내](../WINDOWS_WIDGETS.md)를 참고하세요.

트레이 숫자를 항상 보이게 하려면 **Windows 작업표시줄 설정에서 미터기 트레이 아이콘 표시**를 켜세요. 날씨 영역을 대체하는 기능은 아닙니다.

기존 계정·로그인·사용량 이력·창 배치는 유지합니다. 위젯 이미지와 대체 텍스트에는 이메일·계정 별칭·인증정보·원문 오류를 넣지 않습니다.
