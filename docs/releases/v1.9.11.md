# v1.9.11

- 배치 편집 창이 100% 배율 모니터에서 열린 뒤 150% 모니터로 옮겨 최대화하면, 창은 커지지만 내용이 2/3 크기로만 표시되고 나머지가 검게 남던 문제를 수정했습니다.
- 원인: 최대화 직전에 크기 조절 테두리를 먼저 제거하면 Windows가 창을 이전 모니터의 배율로 축소해 표시했습니다. 이제 화면 크기를 먼저 맞춘 뒤 테두리를 제거합니다.
- 검사: 서브(100%)·메인(150%) 4K 구성에서 본체를 서브에 둔 채 편집 창을 메인으로 옮겨 최대화했을 때, 실제 화면 픽셀이 작업 영역 끝까지 그려지는 것을 확인했습니다. 배치·계정 전환·전체 자체 검사를 통과했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
