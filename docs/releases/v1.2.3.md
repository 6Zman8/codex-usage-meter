# v1.2.3 — 저장된 구독 날짜의 시간대 수정

**⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받습니다. [v1.2.2 웹 구독 연결](v1.2.2.md)을 포함합니다. 전체·위젯에서 각 계정의 초기화권 아래 날짜를 누르면 웹 ChatGPT 계정을 연결할 수 있습니다.

저장된 날짜가 UTC로 복원되어 PC 현지 날짜와 달라질 수 있는 문제를 수정했습니다. 예를 들어 `11월 2일 23:30 UTC`는 한국에서 `11월 3일 08:30`으로 표시하며, 남은 일수도 현지 날짜를 기준으로 계산합니다. 날짜를 하루 잘못 표시하는 회귀검사의 실패를 확인한 뒤 수정했습니다.

웹 계정 조회 자료·로그인·설정은 유지합니다. 실제 인증된 WebView2 로그인 및 인증 세션 보존 후 자동 확인은 사용자 최초 연결 이후 확인할 항목이며, 익명 로그인 화면과 격리된 자동 확인·종료·시간 초과 검사는 통과했습니다.
