# v1.9.14

- Claude 계정의 이메일을 읽지 못하던 문제를 수정했습니다. 사용량은 정상으로 표시되는데도 **claude.ai 연결**이 "먼저 이 칸의 Claude 계정을 연결하라"는 안내로 막혔습니다. 카드에도 이메일 대신 "Claude 계정"만 표시됐습니다.
- 원인: Claude 프로필 응답의 이메일 항목 이름은 `email`인데, 미터기는 `email_address`를 읽었습니다.
- 같은 원인으로 계정 확인 정보가 저장되지 않아, 1분마다 계정 확인 요청이 한 번 더 나가고 있었습니다. 이제 평소에는 1분에 사용량 요청 1번만 보냅니다.
- 검사: 공급자·웹 구독·계정 전환·전체 자체 검사를 통과했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
