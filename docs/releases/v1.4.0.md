# v1.4.0 — 계정별 사용량 이력과 초기화 전 잔여량

미터기의 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받습니다. 업데이트 후 전체·위젯의 **계정 카드 → 이력**을 누르세요.

- 계정별 단기·주간 잔여 비율 변화를 PC에 기록합니다. 저장된 계정과 최근 7/30/90일·전체 기간을 선택할 수 있습니다.
- 초기화 전 마지막 잔여 비율·확인 시각·예정 초기화와의 간격을 보관합니다. 새 주기 조회 후에도 이전 기록이 유지됩니다.
- 현재 주기, 새 한도 확인, 예정 시각 경과 후 갱신 미확인, 잔여량·플랜·한도 변경을 구분합니다.
- 계정 칸을 이동하거나 다른 계정을 연결해도 계정 식별자 해시로 이력이 분리됩니다. 연결 해제한 계정의 기록도 보존합니다.
- 기록은 기존 60초 조회를 이용하며 같은 값은 처음·마지막 확인 시각으로 묶습니다. 월별 원자적 저장과 직전 정상 백업을 사용합니다.

## 관측 범위

새 버전 실행 후 조회한 값부터 기록합니다. 앱이 꺼져 있거나 조회가 실패한 구간, 업데이트 이전의 초기화 전 수치는 복원하지 않습니다. 초기화 직전의 정확한 값으로 표현하지 않고 마지막 관측값을 표시합니다. 토큰 사용량 달력과 기존 계정 전환·Chrome 구독 연결은 유지합니다.

이력은 PC별 `%LOCALAPPDATA%\CodexUsageMeter\usage-history`에 저장합니다. 인증 토큰·대화·Codex DB를 포함하거나 다른 PC로 동기화하지 않습니다. 손상된 이력은 보존하고 오류를 표시합니다.

## 검증

`--usage-history-self-test`는 가상 계정으로 실제 파일 저장·재로드·계정 분리·월 경계·초기화·결측·실패·만료 응답·플랜 변경·손상 보존 및 숨김 WPF 표를 검사합니다. 전체 `--self-test`와 GitHub Release 자동 검사에도 포함합니다. 실제 사용자의 계정을 전환하거나 Codex를 종료하여 시험하지 않습니다.
