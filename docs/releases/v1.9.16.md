# v1.9.16

Claude 카드가 GPT/Codex 카드와 같은 기능과 화면으로 작동합니다. 이름과 기호만 다릅니다.

- **내장 로그인 창 제거**: Claude 연결과 재연결은 기본 브라우저(크롬)에서 로그인합니다. "claude.ai 연결하기"와 미터기 안 claude.ai 창은 없어졌습니다.
- **초기화권 자동 표시**: 1분마다 보내는 사용량 요청 하나로 Claude 한도 초기화(초기화권) 보유 개수와 만료일을 함께 받아옵니다. 요청 횟수는 늘지 않았습니다. 초기화권은 claude.ai의 설정 → 사용량에서 사용합니다.
- **구독 날짜**: GPT와 같은 크롬 구독 연결(탬퍼몽키 스크립트 1.4.0)로 claude.ai의 실제 결제일·종료일을 받아옵니다. 구독 날짜 줄을 누르면 GPT와 같은 안내 창이 열립니다. 스크립트는 탬퍼몽키가 자동으로 업데이트하며, 크롬에서 claude.ai를 열면 반영됩니다. 크롬의 claude.ai 계정·조직이 그 칸의 Claude 계정과 같을 때만 반영하고, 로그인 정보는 보내지 않습니다.
- **재연결·전환 버튼**: Codex와 같은 자리·이름·상태로 표시됩니다. Claude의 **전환**은 Claude Code가 이 칸의 계정을 쓰도록 Claude Code 로그인 파일을 바꿉니다. 실패하면 원래 로그인으로 되돌리며, Claude 데스크톱 앱과 Mixdog 로그인은 건드리지 않습니다. 실행 중인 Claude Code는 다시 시작해야 반영됩니다.
- Claude에 없는 정보는 칸을 숨기지 않고 Codex와 같은 "정보 없음" 문구로 표시합니다. 사용 통계는 Claude가 토큰 수를 제공하지 않아 주간 한도 %로 표시합니다.

검사: 공급자·크롬 구독·웹 구독·배치·위젯·계정 전환·요청 제한·업데이트 UI·트레이·사용량 이력·전체 자체 검사를 통과했습니다. 전환 검사는 실제 사용자 폴더가 아닌 격리된 임시 폴더에서 진행했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
