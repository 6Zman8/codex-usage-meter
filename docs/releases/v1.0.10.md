# Codex Usage Meter 1.0.10

계정 전환 후 Codex가 실제로 실행되어도 시작 실패로 판단하던 프로세스 분류 오류를 수정했습니다.

- Windows가 미터기를 새 Codex의 부모 프로세스로 지정한 경우, 기존 분류는 Codex와 그 백엔드까지 미터기 보호 대상으로 제외했습니다. 새 분류는 설치된 Codex로 확인한 프로세스를 별도 분기로 인식합니다.
- 미터기 자체와 계정별 사용량 조회 연결은 계속 보호합니다. 시작 실패 복구에서도 실제 Codex 종료를 확인한 뒤 인증정보를 되돌리는 기존 순서를 유지합니다.
- 미터기의 직접 자식으로 시작한 Codex와 중간 실행 도우미를 거쳐 시작한 Codex를 모두 검사합니다. 시작 안정성, 종료 확인, 미터기 연결 보존에 대한 회귀검사를 추가했습니다.

## 검증 범위

기존 설치본의 분류 함수를 오류 당시 실제 프로세스 관계에 적용해 누락을 재현했습니다. 추가한 회귀검사는 수정 전 실패했고 수정 후 통과했습니다. 사용자 계정과 프로세스를 바꾸지 않는 격리 자체검사 및 읽기 전용 프로세스 대조로 검증했습니다. 사용자의 실제 계정 전환 성공은 별도 확인이 필요합니다.

## 업데이트

미터기의 `⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작`으로 v1.0.10을 받으세요. 기존 계정 연결과 설정은 유지됩니다. 공개 Release 안내는 구버전 미터기에서도 버튼이 잘 보이도록 짧은 영문 한 줄로 제공하며, 상세 변경사항은 이 문서에 보관합니다.
