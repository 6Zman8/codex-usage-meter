# v1.8.0

- Windows 위젯에 미터기의 계정 게이지·색상·저장 순서·표시 항목·내부 배치를 함께 반영합니다. 작은 위젯은 카드 넘기기로 읽을 공간을 확보합니다.
- 본체 업데이트 후 이미 설치된 구버전 Windows 위젯도 같은 정식 버전으로 갱신합니다. 미설치·같은 버전·더 최신 버전은 건드리지 않습니다.
- 배치 편집에서 항목을 이동·크기조절하면 다른 항목과 카드의 경계·중앙선에 맞춰집니다. 파란 안내선이 표시되며 `Alt`로 일시 해제합니다.
- PC 상태는 원형 대신 CPU·GPU·RAM·디스크 세로 막대를 사용합니다. 계정의 원형 게이지는 유지합니다.
- 기존 저장 위치·크기·순서·표시/숨김을 유지합니다. 업데이트나 화면 확대만으로 자동 정렬하지 않습니다.

기존 앱의 **설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받습니다. 테스트는 실행 중인 앱이나 사용자 계정·인증·세션을 바꾸지 않는 격리 환경에서 수행합니다. 실제 Windows 보드 적용 여부는 배포 검증 기록에서 별도로 구분합니다.
