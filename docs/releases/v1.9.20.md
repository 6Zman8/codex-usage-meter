# v1.9.20

- **로그인된 계정 순서 조절**: **⚙ 설정 → 계정 순서**에서 ▲▼ 버튼으로 계정을 옮길 수 있습니다. 맨 위 계정이 "계정 1"이 되며, 카드 제목·번호 배지·페이지 표시·배치 편집·트레이 계정 선택·Windows 위젯에 같은 번호가 쓰입니다. 전체 화면과 위젯 화면의 계정 카드도 새 순서로 정렬되며, PC 상태 카드 위치와 카드 크기·숨김 설정은 유지됩니다.
- 로그인 정보는 계정 칸별 폴더에 그대로 남고 표시 순서만 바뀝니다. 순서는 레지스트리 `AccountOrder` 값에 저장됩니다. 트레이에 표시하던 계정은 순서가 바뀌어도 같은 계정으로 유지됩니다.

검사: 전체 자체 검사(`--self-test`), 배치·위젯·계정 전환 자체 검사를 통과했습니다. 계정 순서 정규화·이동·카드 재배치 검사를 추가했습니다.

기존 프로그램에서 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 받으세요.
