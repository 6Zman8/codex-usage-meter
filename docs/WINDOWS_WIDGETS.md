# Windows 위젯 보드에서 사용량 보기

미터기의 **⚙ 설정 → 업데이트 확인 → 다운로드 및 재시작**으로 v1.6.0 이상을 받으세요.

1. **⚙ 설정 → Windows 위젯 추가 / 업데이트**를 누릅니다.
2. 개발자 모드 안내가 나오면 **Windows 설정 열기**를 눌러 개발자 모드를 켠 뒤 미터기의 같은 버튼을 다시 누릅니다. 이 GitHub 배포판은 Windows의 로컬 위젯 등록 방식을 사용합니다. 미터기가 보안 설정이나 인증서 신뢰를 자동으로 바꾸지는 않습니다.
3. 등록이 끝나면 **Win+W → 위젯 추가 → Codex 사용량**을 선택해 고정합니다. Windows 버전에 따라 위젯 추가 메뉴의 위치가 다를 수 있습니다.
4. 미터기의 **▁** 버튼으로 창을 트레이에 숨기세요. 숨겨진 동안에도 기존 60초 간격 사용량 조회가 유지됩니다. **미터기 열기**나 작업표시줄 고정 아이콘을 누르면 기존 창이 다시 열립니다.
5. 다음 로그인부터 창 없이 유지하려면 **로그인 시 시작**과 **자동 시작 시 트레이로**를 함께 켭니다. 일반 실행 아이콘으로 열 때는 창이 표시됩니다.

위젯의 **새로고침**은 창을 띄우지 않고 기존 미터기에 갱신을 요청합니다. 미터기가 꺼져 있으면 트레이로 실행합니다. 미터기 종료 후에는 실시간 사용량을 조회하지 않으므로 위젯의 상태와 마지막 확인 시각을 함께 확인하세요.

## 표시와 보존 범위

- 계정 번호·요금제·잔여 비율·초기화 시각·마지막 실제 관측 시각을 표시합니다. 이메일이나 인증정보는 전달하지 않습니다.
- 실제 0%, 한도 미제공, 연결되지 않은 계정, 조회 실패와 확인 대기를 구분합니다. 3분 이상 지난 관측은 오래된 자료로 표시합니다.
- Windows 위젯과 앱 안의 기존 작은 `위젯` 화면은 서로 독립적입니다. 기존 전체/작은 화면 배치 설정은 유지됩니다.
- 위젯은 읽기 전용 요약입니다. 계정 연결·전환·상세 이력·화면 배치 변경은 **미터기 열기**에서 합니다.
- 자료는 `%LOCALAPPDATA%\CodexUsageMeter\windows-widget`에만 저장하며 다른 PC에 자동 복사하지 않습니다. `snapshot.json`은 최소 요약, `app-path.txt`는 설치된 미터기의 실행 경로입니다. 기존 계정·인증·사용량 이력에는 손대지 않습니다.

## 설치·업데이트

Windows 11 64비트와 Windows Web Experience Pack이 필요합니다. 제공자 패키지는 현재 미터기와 같은 버전의 정식 GitHub Release에서 받아 크기·SHA-256·패키지 식별자·버전을 검증한 뒤 현재 Windows 사용자에게 등록합니다. .NET 런타임은 위젯 패키지에 포함됩니다. 별도 .NET 설치나 인증서 설치는 요구하지 않습니다.

미터기를 업데이트한 뒤 위젯 구성요소도 바꾸려면 **Windows 위젯 추가 / 업데이트**를 다시 누르세요. 자동 다운로드는 하지 않습니다. 새 구성요소는 별도 버전 폴더에 준비하므로 다운로드·검증 실패로 이전 파일을 덮어쓰지 않습니다. 등록 오류 기록은 해당 설치 폴더의 `registration.log`에 남습니다.

Windows에서 개발자 모드를 허용하지 않는 관리 PC에서는 이 로컬 등록판을 사용할 수 없습니다. 개발자 모드를 켜지 않는 일반 배포는 Microsoft Store 배포 절차가 별도로 필요하며, 현재 GitHub Release를 Store 앱으로 설명하지 않습니다.

공식 근거: [Microsoft Widgets 샘플과 배포 조건](https://github.com/microsoft/WindowsAppSDK-Samples/blob/main/Samples/Widgets/README.md), [패키지 등록 명령](https://learn.microsoft.com/en-us/powershell/module/appx/add-appxpackage).

## 개발 및 검증

본체는 기존 `build.ps1`과 .NET Framework 컴파일러로 빌드합니다. 별도 위젯 구성요소만 `build-windows-widget.ps1`로 빌드하며, 세부 사항은 `windows-widget`의 문서를 확인하세요.

- 본체 `--single-instance-self-test`: 별도 프로세스 요청, 숨김/최소화/반복 복원, 시작 경합, 숨김 새로고침. 실제 미터기와 다른 이름의 엔드포인트를 사용합니다.
- 본체 `--windows-widget-self-test`: 익명 스냅샷·오류/한도 구분·원자적 저장, ZIP 경로·해시·패키지 신원 검증, 숨김 설정 화면의 작은 창/큰 글씨 검사.
- 본체 `--windows-widget-download-test`: 현재 정식 릴리스의 위젯 패키지를 다운로드하고 검증합니다. 패키지 등록은 하지 않습니다.
- 제공자 검사와 실제 Windows 보드 표시/고정/갱신은 구분합니다. 빌드 성공이나 카드 JSON 검사만으로 Windows 보드에서 확인했다고 판단하지 않습니다.
