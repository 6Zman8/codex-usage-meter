# 웹 ChatGPT 구독 연결

## 목적과 범위

각 계정의 초기화권 아래에서 구독 날짜를 클릭하면 웹 ChatGPT 연결 창을 엽니다. 계정마다 한 번 로그인하면 앱은 해당 웹 프로필을 이용해 백그라운드로 구독 정보를 확인합니다. 기존 Chrome·Codex 로그인과 사용자 작업은 보존합니다. 날짜는 직접 입력하지 않습니다.

2026-10-06 조사에서 Codex 인증의 결제 API 요청은 403이었지만, 정상 로그인된 Chrome의 같은 계정 조회는 200이었습니다. 웹 결제 화면의 플랜 전환 안내와 `entitlement.scheduled_plan_change`가 일치했습니다. 실제 계정 식별자·결제 내역·인증 자료는 문서와 저장소에 넣지 않습니다.

## 설계

- Microsoft WebView2의 정상 웹 탐색 중 계정 조회 응답만 읽습니다. 웹 쿠키나 토큰을 추출하거나 Codex 인증으로 복사하지 않습니다.
- 미터기에 연결된 계정 ID와 현재 플랜을 확인한 응답만 반영합니다. 조회 도중 계정이 변경되면 폐기합니다.
- `renews_at`, 취소·종료, `scheduled_plan_change.changes_at`를 구분합니다. 플랜 전환은 `11/2 → Plus`처럼 표시합니다.
- 웹 프로필과 최소 날짜 캐시는 해당 PC의 미터기 계정 폴더에 보관합니다. 저장소·다른 PC로 옮기지 않습니다.
- 연결 후 6시간마다 확인하고, 실패 시 1시간 간격으로 재시도합니다. 24시간이 지난 날짜를 현재 정보처럼 표시하지 않습니다. 백그라운드 실패는 로그인 창을 자동으로 띄우지 않습니다.
- WebView2 Runtime은 PC 설치본을 사용합니다. SDK 구성 요소는 버전·SHA-256을 고정해 단일 EXE에 포함합니다. 기존 GitHub Release → 내장 업데이트로 전달합니다.

실제 웹 로그인 및 자동 확인 검증과 익명·격리 검사 결과를 최종 기록에서 구분합니다.

## 2026-10-06 검증 기록

- 전체 회귀검사, 계정 전환 검사, 숨김 WebView2 정상 응답·재실행·초기화 취소·25초 시간 초과 검사: 종료 코드 0.
- 실제 익명 WebView2: ChatGPT 로그인 화면 도달, 해당 관찰 시점에 보안 확인 화면 없음. 실제 계정의 로그인·세션 보존 후 재조회는 사용자 최초 연결 이후 확인할 항목입니다.
- 실제 Chrome 계정 응답의 날짜를 연결 계정 1에 대조하여 로컬 캐시에 저장했습니다. `auth.json` 해시 불변. `WebProfileLinked=false`로 저장하여 날짜 관찰과 지속적인 웹 연결을 구분합니다.
- 구독 날짜 클릭은 전체·위젯 양쪽에 제공됩니다. 100~200% 글씨와 좁은 창의 기존 정렬·모든 카드 표시 검사를 통과했으며 미리보기 이미지를 확인했습니다.
- 별도 읽기 전용 코드 검토: 수정이 필요한 확정 결함 없음. 브라우저 Runtime 강제 비정상 종료와 실제 외부 로그인 공급자 인증은 확인하지 않았습니다.
- 상세 검사 자료: `artifacts/web-subscription-20261006/` (개인 자료·실제 응답은 Git 제외).
