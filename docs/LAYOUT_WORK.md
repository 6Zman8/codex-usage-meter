## 확정 범위

사용자는 카드 방식(숨김·표시, 드래그 순서 변경, 카드 크기·열 수 조절)을 선택했습니다. 전체 화면과 위젯 설정은 독립적으로 저장합니다. 계정 연결 수와 화면 표시를 분리하며 계정 자료를 삭제하거나 복사하지 않습니다.

계정 카드와 PC 카드의 순서·폭·높이를 편집합니다. 계정 카드의 단기/주간 한도·초기화권·통계·달력, PC 카드의 CPU/GPU/RAM/디스크/네트워크를 개별 표시합니다. 위젯은 원래 제공하던 항목을 편집합니다. 좁은 창은 자동 줄바꿈/스크롤로 표시하고, 기존 창 크기 조절과 계정 전환 기능을 보존합니다. 한 계정 중심 프리셋은 선택 계정만 화면에 표시하며 연결 수는 바꾸지 않습니다.

## 주의할 경계

- 계정 3~4개, 일부 계정만 표시, PC만 표시, 전부 숨긴 상태에서도 편집/복구 가능해야 합니다.
- 저장 실패는 성공으로 표시하지 않으며 취소 시 편집 전 배치로 되돌립니다.
- 조회 실패/아직 연결하지 않은 계정을 ‘제공되지 않는 한도’로 판단해 숨기지 않습니다.
- 카드 폭보다 좁은 창과 큰 글씨에서 조작 버튼과 내용을 잘라 버리지 않습니다.
- 기존 설치와 실행 중인 프로세스는 시험용 빌드와 분리합니다.
