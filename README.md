# Codex 사용량 미터기

Codex 계정 1~4개의 사용량과 Windows PC 자원 사용량을 한 화면에 상시 표시하는 WPF 앱입니다.

## 실행

`bin\CodexUsageMeter.exe`를 더블 클릭하면 됩니다. 실행 파일이 아직 없다면 PowerShell에서 `build.ps1`을 한 번 실행하세요.

## 업데이트

자동 업데이트 확인은 하지 않습니다. 사용자가 상단 `⚙` 설정을 열고 `업데이트 확인`을 누른 경우에만 공개 GitHub 저장소의 최신 정식 Release를 조회합니다. 위젯과 전체 화면 어느 쪽에서도 새 버전 확인창과 `다운로드 및 재시작` 버튼이 즉시 표시됩니다.

새 버전이 있으면 사용자 확인 후 `CodexUsageMeter.exe`를 로컬 임시 폴더로 다운로드하고 GitHub Release의 SHA-256 digest와 대조합니다. 검증이 끝나면 실행 파일에 내장된 작은 교체 도우미가 현재 프로그램 종료를 기다려 기존 EXE를 교체하고 다시 실행합니다. 교체나 새 버전 시작에 실패하면 기존 EXE로 복구합니다. 평상시 프로그램 폴더에는 실행 파일 하나만 필요합니다.

긴 업데이트 안내는 창 안에서 스크롤되며, 아래의 `나중에`와 `다운로드 및 재시작` 버튼은 계속 표시됩니다. 작은 창에서는 버튼 글자가 줄바꿈되고, 한글 안내는 UTF-8로 읽습니다. 이전 버전에서 안내가 잘려 버튼이 안 보이면 `Esc`를 두 번 눌러 닫고 `⚙ 설정 → 업데이트 확인`을 다시 누르세요. 이전 버전도 받을 수 있도록 공개 업데이트 요약은 짧은 영문으로 제공합니다.

## 계정 연결

작은 위젯에서 `전체`를 눌러 큰 화면으로 전환한 뒤 아래 순서로 연결합니다.

1. 계정 1 카드의 `연결`을 누릅니다.
2. 표시된 코드가 클립보드에 복사되고 OpenAI 기기 인증 페이지가 열립니다.
3. 계정 1로 로그인해 코드를 입력합니다.
4. 다른 계정 칸도 같은 방식으로 연결하되, 브라우저에서 반드시 해당 계정을 선택합니다.
5. 계정을 더 쓰려면 상단 `⚙` 설정에서 계정 칸 수를 늘리고, 하단 계정 페이지 버튼으로 다음 두 칸을 엽니다.

다른 프로그램이 Windows 클립보드를 잠시 점유해 자동 복사가 실패해도 로그인은 중단되지 않습니다. 안내창에 표시된 코드를 직접 입력하거나 `코드 복사`를 다시 누르면 됩니다.

두 계정은 다음 전용 폴더에 각각 분리되어 저장됩니다.

- `%LOCALAPPDATA%\CodexUsageMeter\accounts\account-1`
- `%LOCALAPPDATA%\CodexUsageMeter\accounts\account-2`부터 `account-4`까지

설정에서 칸 수를 줄여도 해당 계정 프로필은 삭제하지 않습니다. 나중에 칸 수를 다시 늘리면 기존 연결을 다시 확인할 수 있습니다.

폴더가 있다는 이유만으로 수동 등록 계정으로 세지 않습니다. 미터기가 실제 인증 상태를 확인한 계정 칸에만 전환 버튼을 표시합니다.

평상시 사용량 조회는 계정별 전용 폴더에서 독립적으로 동작합니다. `Codex로 전환`을 누른 경우에만 선택 계정의 인증정보를 검증한 뒤 현재 Codex 로그인 파일에 안전하게 적용합니다. 인증 토큰 내용은 화면이나 로그에 표시하지 않습니다.

Codex 데스크톱 앱이 업데이트되어 내부 `codex.exe` 위치가 바뀌어도, 미터기는 사용량 연결을 시작하거나 다시 연결할 때마다 현재 설치된 최신 실행파일을 다시 찾습니다. 기존 인증정보는 그대로 사용하므로 계정을 다시 등록할 필요가 없습니다.

## Codex 계정 전환

미터기에 연결된 계정 카드의 `Codex로 전환`을 한 번 누르면 다음 작업을 자동으로 수행합니다.

1. 진행 중인 사용량 갱신을 기다린 뒤 계정별 연결만 잠시 멈춥니다. 더 최신인 인증정보를 보존하고, 선택 계정의 인증을 갱신·확인합니다. 이 확인에 실패하면 Codex는 종료하지 않습니다.
2. Codex 데스크톱 앱과 Codex에 딸린 내부 프로세스만 완전히 종료합니다.
3. 선택 계정의 인증정보를 원자적으로 적용합니다.
4. Codex를 다시 열고 응답하는 창과 Codex 소속 내부 연결 프로세스가 3초 이상 유지되는지 확인합니다. 업데이트 직후 실행 준비가 늦어지는 경우 최대 60초까지 기다립니다. 이 검사는 시작 상태 확인이며 실제 대화 요청의 성공까지 보장하지는 않습니다.

유효한 계정 인증이 있으면 브라우저 로그인이나 별도의 재시작 버튼은 필요하지 않습니다. Codex를 완전히 종료하지 못하면 인증정보를 바꾸지 않습니다. 새 계정으로 다시 여는 데 실패한 경우, 부분적으로 시작된 Codex를 먼저 완전히 종료한 뒤 기존 인증정보를 복원합니다. 이 종료도 확인하지 못하면 서로 다른 계정 정보가 섞이지 않도록 선택 계정의 인증을 유지하고 실패를 알립니다. 미터기와 미터기용 계정별 app-server는 Codex에서 미터기를 실행했더라도 종료 대상에서 제외합니다.

현재 계정의 `Codex 다시 연결`(위젯에서는 `재연결`)로 다른 계정에 갔다 올 필요 없이 같은 계정의 Codex를 완전히 다시 열 수 있습니다. 종료 순간에 프로세스 조회가 실패하면 실제 종료 여부를 다시 확인합니다. 종료 확인이 끝내 실패한 경우에는 계정 정보를 변경하지 않고 기존 계정으로 Codex를 다시 여는 복구를 시도합니다. 전환 단계와 프로세스 번호는 `%LOCALAPPDATA%\CodexUsageMeter\account-switch.log`에 기록하며, 이메일이나 인증 토큰은 기록하지 않습니다.

## 표시 항목

- 계정별 5시간/주간 사용량 잔여 비율, `MM/DD HH:mm` 형식의 초기화 시각, 오른쪽 정렬된 남은 시간과 감소형 시간 게이지
- 현재 시점의 권장량을 실제 값 아래에 같은 크기의 연한 색 게이지로 깔아 두고, 과사용 구간만 드러나게 표시
- 초기화권 보유 개수와 가장 빠른 만료일·남은 유효기간
- 누적 토큰, 최고 일간 사용량, 현재/최장 연속 사용일, 최장 작업 시간
- 이전 달·이번 달·다음 달을 넘겨 보는 일~토 순서의 일별 토큰 달력과 월 누계
- 최근 7일 사용량은 6일 전부터 오늘까지 왼쪽에서 오른쪽으로 표시하고, 각 막대 아래 날짜와 오른쪽 끝 `오늘`을 표시
- CPU와 RAM, 감지된 모든 GPU의 개별 사용률
- 감지된 모든 물리 디스크(SSD/HDD)의 개별 활성 시간과 읽기·쓰기 속도
- 활성화된 물리 네트워크 어댑터별 다운로드·업로드 속도와 링크 사용률
- PC 성능 항목마다 최근 60초 변화 그래프
- 항상 위 표시, 트레이 최소화, 사용자가 선택하는 Windows 로그인 시 자동 시작

비용 추정은 의도적으로 포함하지 않았습니다. 달력에는 월간 토큰과 최근 7일 토큰만 표시합니다. Codex가 토큰당 한도 환산 공식을 제공하지 않으므로 실제 한도 퍼센트는 5시간/주간 게이지의 서버 값을 그대로 표시합니다. 계정 사용량은 60초마다, PC 자원과 리셋 카운트다운은 1초마다 갱신됩니다. `갱신`을 누르면 계정 사용량을 즉시 다시 읽습니다.

앱은 코덱스 다크 모드와 어울리는 짙은 회색·녹색 계열의 전용 UI를 사용합니다. 기본 대시보드에는 스크롤바가 없고, 긴 알림에만 스크롤바가 나타납니다.
프로젝트의 `아이콘.png`를 창 아이콘에는 직접 사용합니다. 실행 파일과 트레이에는 Windows 규격상 ICO가 필요하므로 PNG 원본 데이터를 재인코딩 없이 담은 아이콘을 사용합니다.

- 기본 `위젯` 화면: 460×780 크기로 화면 오른쪽 위에 열립니다. 계정마다 큰 보라색 `주간` 게이지와 별도의 민트색 `5시간` 게이지를 나란히 배치하고 두 퍼센트를 각각 중앙에 표시합니다. 연한 권장량 게이지를 아래 레이어에 먼저 그리고 진한 실제 값을 위에 덮어, 실제 값이 권장량보다 낮아진 구간만 연한 색으로 드러납니다. 갱신까지 남은 시간은 원형 게이지와 겹치지 않는 오른쪽 전용 영역에서 숫자와 감소하는 가로 막대로 표시합니다. PC의 CPU·GPU·RAM·디스크도 5시간 게이지와 같은 크기로 2×2 배치합니다. 상단 `TOP` 버튼으로 항상 위를 켜거나 끌 수 있으며 최초 기본값은 꺼짐이고 이후 선택 상태가 저장됩니다.
- `전체` 화면: 두 계정 칸과 PC 자원의 3열 대시보드입니다. 계정이 3~4개면 하단 화살표로 두 칸씩 넘겨 봅니다. 달력과 감지된 GPU·물리 디스크·물리 네트워크 어댑터를 각각 표시하고, PC 카드에는 최근 60초 그래프를 그립니다. 위젯의 단일 GPU·디스크 칸은 매 측정 시점에 사용률이 가장 높은 실제 장치를 골라 번호와 사용률을 보여줍니다.
- 큰 화면의 `위젯`, 작은 화면의 `전체` 버튼으로 즉시 오갈 수 있으며 연결과 갱신 상태는 그대로 유지됩니다.
- 위젯과 전체 화면 모두 앱 자체의 최소 크기 제한 없이 네 모서리 또는 가장자리를 끌어 자유롭게 조절할 수 있습니다. 조절 중 `Shift`를 누르면 현재 모드의 기본 비율이 유지됩니다. 네 귀퉁이는 30px 범위로 넓게 잡히며, 모드를 오갈 때 각 모드에서 마지막으로 사용한 크기가 유지됩니다. 투명 그림자용 외곽 여백과 Windows의 6px 비클라이언트 프레임을 사용하지 않아 PowerToys FancyZones 영역을 끝까지 채웁니다.
- 위젯과 전체 화면의 `□` 버튼 또는 제목 표시줄 더블 클릭으로 최대화할 수 있습니다. 최대화는 현재 모니터의 작업 영역까지만 사용하므로 작업표시줄을 덮지 않습니다. 최대화 후 `❐` 버튼이나 제목 표시줄을 다시 더블 클릭하면 이전 크기로 복원됩니다. 상단의 `전체`는 최대화가 아니라 상세 레이아웃 전환입니다.
- 상단 `⚙` 설정창에서 계정 칸 수(1~4개), 글자 크기(100~200%, 기본 150%), `로그인 시 시작`을 조절할 수 있습니다. 상단의 설정·닫기·최대화 같은 아이콘 크기는 글자 배율에 영향을 받지 않습니다. 계정 칸 수·글자 크기·항상 위·로그인 시 시작은 앱을 완전히 종료했다가 다시 실행해도 유지됩니다.

## 종료

창의 `×` 또는 `Alt+F4`는 앱을 완전히 종료합니다. `▁` 버튼을 누른 경우에만 트레이로 숨겨지며, 이때는 트레이 아이콘을 더블 클릭해 다시 열거나 오른쪽 클릭 후 `종료`할 수 있습니다.
